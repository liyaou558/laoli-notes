> 播客：跨国串门儿计划 #700（克隆自 Sub Club by RevenueCat）| 时长：约 58 分钟 | 原内容更新：2025-04-02 | 来源：小宇宙
> 对谈：Sub Club 主持人 David Barnard 与 RevenueCat CEO Jacob Eiting × Portola 联合创始人 Ajay Mehta，围绕 AI 情感陪伴应用 Tolan 的产品与增长。*本笔记基于 show notes 整理，非完整转录稿。*

## 一、核心观点

### 1. AI 正在创造「过去根本不存在的消费品类」，而非只是优化旧应用
Ajay 认为，生成式 AI 的意义不在于让 ChatGPT 类产品「更聪明」，而是让情感陪伴、实时互动、持续记忆、个性化回应等过去无法实现的体验第一次成为可能。他直言「还有另一个维度，那就是所有那些以前根本不可能做出来的全新细分领域」——团队刻意从儿童与青少年用户切入，探索生成式 AI 能构建哪些全新的消费级产品，最终在 ChatGPT 与 Midjourney 爆发后找到了「情感陪伴」这条新赛道。

### 2. 消费级 AI 的核心是让用户感觉「屏幕另一端有人在懂你」
Tolan 没有把 AI 包装成更高效的工具，而是塑造一个可交互、会记住你的 AI 外星人朋友。Ajay 强调价值不只在回答是否正确，更在于 AI 是否记得你、理解你、让你愿意回来——「AI 真正能让你做到的，就是打造一种 C 端体验，让人感觉屏幕另一端完全有一个懂你、了解你的存在」。这也是他从「朋友」而非「助手」切入陪伴品类的原因，并刻意避开恋爱与性暗示的叙事。

### 3. 被迫提前收费不是阻碍，而是产品价值的验证器
Tolan 上线初期并未立刻收费，但用户每天长时间使用带来巨额模型与语音 token 成本，倒逼团队尽早商业化。Ajay 认为这是「打磨产品的倒逼机制」——通过真实的续费与流失信号，团队能更早判断用户是否真正获得价值，而非被免费期的虚高使用数据误导。高昂基础设施成本逼出的定价决策，反而加速了价值验证与产品取舍。

### 4. 低延迟语音 + 记忆检索 + 实时动画，构成 AI 陪伴的技术护城河
自然连贯的 AI 对话远不止接入一个模型 API。Tolan 同时处理语音响应、记忆检索、对话分类、多个 prompt 与 Unity 实时渲染，目标是让用户感到交流足够快、足够连贯并延续过去上下文。Ajay 断言：「一旦你真正动手去打造极致的语音 AI 体验，你就会明白为什么 App Store 上只有两三款，而不是几十款」——极致语音远比「调用 GPT」困难，是极难被 API 复制的壁垒。

### 5. 视觉设计本身就是分发系统
Tolan 的角色、动画、色彩与星球场景不只是「好看」，而是让产品能在截图、短视频和用户分享中被迅速识别。Ajay 用金句「伟大的视觉设计不只是装饰，也是分发」概括：一个视觉 IP 鲜明的 AI 伴侣，更容易被用户带入社交生活并形成自然传播；团队还与独立艺术家合作打造视觉 IP，并依托 Unity 实时渲染实现可互动的角色。

### 6. TikTok 增长的核心不是精致广告，而是高频试错 + 创作者合作
团队没有押注单条「完美广告」，而是长期与一批创作者合作，持续测试学习、做饭、化妆、恋爱建议等不同内容切入点（含半内部团队与付费植入两种合作模式）。Ajay 的经验是「你试上一堆，大概 20 条里能爆一条，但一旦爆了，就真的能冲出逃逸速度」——一条爆款视频可带来上万次安装，用大量低成本实验去赌内容击中算法与用户的瞬间。

### 7. 创意 IP 与用户心智，可能比底层模型更难被复制
底层模型会被持续迭代、也可能经 API 被竞争者调用，但独特角色、长期打磨的互动细节和用户形成的品牌认同很难被简单复制。Ajay 判断「大部分利润捕获会发生在那个无法通过 API 复制的可爱角色上」——应用层的价值，正来自那些无法被 API 直接替代的体验与品牌认同，这也是创意护城河的所在。

### 8. 9 人团队在 PMF 之后，最难的是拒绝「看起来都该做」的事
增长起飞后团队同时面临本地化、留存、功能开发、团队建设、全球化与 App Store 榜首后的规模压力，Ajay 反复用「因为我们只有 9 个人，我们现在做不到」来划清边界。他认为早期团队不可能一次做完所有事，最关键的是持续打磨核心体验，用用户反馈与留存决定优先级，让留存成为陪伴类产品的北极星指标。

## 二、关键问答

**Q: Tolan 是怎么诞生的？**
A: 在 ChatGPT 与 Midjourney 爆发之后，Portola 团队开始思考生成式 AI 能创造哪些过去根本不存在的消费级产品，从儿童与青少年用户切入探索，最终找到「情感陪伴」方向，做出一个可交互、个性化的 AI 外星人朋友 Tolan，而非单纯提升效率的工具。

**Q: 三位联合创始人是怎样凑到一起的？**
A: Ajay 是连续创业者，曾在消费级金融科技 Wealthsimple 任职、在 YC 创办社交网络 FamilyLeaf，还自筹资金运营过个性化电商；另两位联合创始人 Quinton Farmer 与 Evan Goldschmidt 此前共同创办金融科技公司 Even 并最终被沃尔玛收购。三人的消费产品 + 创业融资 + 增长经验互补。

**Q: 为什么这一轮 AI 浪潮特别适合做消费级产品？**
A: Ajay 认为这次生成式 AI 第一次让许多过去无法实现的 C 端体验成为可能——实时对话、情绪理解、持续记忆、个性化内容、融入日常生活的数字陪伴。这些全新细分领域本身就是 PMF 的机会，而不只是让旧应用变聪明。

**Q: 从 pre-seed 到 1000 万美元融资，为什么这个使命需要 VC？**
A: 团队认为「情感陪伴」这一使命需要足够的研发与基础设施投入，单靠自筹难以为继，因此选择引入风险投资（后续达 1000 万美元融资轮）来支撑语音、记忆与实时渲染等重研发，以及早期高昂的 token 与模型成本。

**Q: 为什么从「朋友」而不是「助手」切入，且避开恋爱叙事？**
A: Tolan 定位是带来温暖、有个性的陪伴关系，价值建立在「记得你、理解你」之上，而非完成任务。团队刻意避开恋爱和性暗示叙事，把 Tolan 做成适合儿童、青少年乃至全年龄段都能建立健康情感连接的 AI 朋友。

**Q: 团队如何判断是否找到了 PMF？**
A: 关键信号来自真实使用与留存：用户每天与 Tolan 聊 30 到 40 分钟，说明产品提供了持续价值；结合付费墙后的续费与流失数据，而非被免费期虚高使用量误导。团队据此判断哪些功能真正打动用户。

**Q: Tolan 的产品体验靠什么支撑？**
A: 低延迟语音 AI、记忆检索系统、实时交互与 Unity 实时渲染的角色动画共同构成体验；onboarding 通过个性测试和记忆系统让用户感到「被理解」，快速带用户到达「第一次长谈」的激活时刻，从而促成留存。

**Q: TikTok 增长的具体打法是什么？**
A: 从创作者内容与小额广告测试起步，围绕学习、做饭、化妆和情感问题等场景切入，建立半内部团队 + 付费植入两种创作者合作模式。靠高频低成本实验去赌爆款——约 20 条中爆 1 条，一条爆款即可带来上万次安装，强调产品—市场—渠道三者的匹配。

**Q: 为什么视觉鲜明的 AI 伴侣天然适合短视频分发？**
A: 因为 Tolan 的角色、动画、星球场景在截图与短视频里能被一眼识别、易于分享与二次创作，符合 TikTok 原生内容的高识别度与可玩性需求。当 UGC 自发出现，分发就形成「增长飞轮」，无需持续砸钱买量。

**Q: 为什么价值最终可能流向无法被 API 复制的应用层？**
A: 底层模型会被持续迭代也能经 API 被调用，但独特角色、长期打磨的互动细节、用户品牌认同极难复制。Ajay 判断大部分利润会留在「无法用 API 复制的可爱角色」上，所以极致语音与角色 IP 本身才是长期护城河。

**Q: 病毒式传播冲到 App Store 榜首后，团队下一步怎么做？**
A: Ajay 认为关键是别被各种机会带偏：9 人团队要同时应对本地化、全球化、留存、功能与团队建设，只能继续改善核心体验、用用户反馈决定优先级，让留存作为陪伴类产品的北极星指标来指引取舍。
