## 一、核心观点

### 1. 现代后训练拼的不是单一技术，而是整合组织架构图的能力

Nathan 直言，把 OMO3 后训练成推理模型，对很多人来说都是一项重大成就，但这也意味着 OMO3 的后训练复杂度已经逼近 AI2 组织能力的极限。现代后训练的本质，是把算力和数据整合进一条工作流的能力——本质上是在整合一张组织架构图。这也是为什么 OMO3 作为推理模型推出得相当晚，且配方相对简单。金句："很多现代后训练，拼的就是你把算力和数据整合进一条工作流的能力。"

### 2. 配方趋同的分岔点出现在 TULU3 之后

在 TULU3 之前，大家还能说"做法都差不多"——SFT、DPO、RL 三阶段配方足以概括主流做法。但到了推理模型和带工具使用的 Agent 模型时代，那种简单配方已经不再适用，前沿实验室的做法与开放学术界的差距正在急剧拉大。Finbarr 指出，TULU3 是一个明确的分岔点：在此之前是"简单配方 vs 前沿做法"的模糊地带，在此之后简单配方彻底失效。

### 3. DPO 的消失是配方工业化的必然结果

当后训练流程变得越来越精细、越来越工业化，DPO 能带来的边际收益就消失了；但在配方粗糙的阶段，DPO 依然是从零搭建时算力效率最高的选择之一。Nathan 直言："用 DPO 的人可能会被看不起，但如果你是想把一个配方从零搭起来，它仍然管用。" Finbarr 补充："当你的配方越来越干净的时候，这个需求基本上就消失了。" 二人同时也承认偏好调优本身可能被低估——偏好损失函数有时能带来惊人的提升。

### 4. 多教师在线策略蒸馏是 2026 年最值得关注的新范式

在 RL 框架内，让正在训练的学生模型采样轨迹，再路由给各个领域专家教师，用 KL 散度损失对齐，这就是多教师在线策略蒸馏的核心机制。DeepSeek V4 率先实践了这一方向，而 MIMO Flash V2 命名了该术语。Finbarr 强调，实现起来其实很直接——只需要对现有 RL 配置做一小套调整："你拿你现有的 RL 配置，然后只需要对学习者模型做一小套调整，就能实现这个。"

### 5. 教师模型差异过大，蒸馏会失败

英伟达在 Nematron 3 Ultra 论文中披露了一个关键发现：用差异很大的训练流程训练出来的教师模型，无法通过简单的在线策略蒸馏有效合并。教师和学生若用不同 SFT 数据训练，会习得不同的推理行为，导致学生轨迹对教师而言属于分布外数据。"这种分布差异会导致学生生成的轨迹对教师来说属于分布外数据，从而降低教师提供的监督信号的质量和可靠性。"

### 6. 中国实验室更愿意分享"特别特别具体"的细节

从温度调度到难度课程，KIMI K2.5 和 GLM5 分享了大量可操作的配方细节——尽管两者在温度调度上声称的方向正好相反。相比之下，英伟达的论文更像一份方法列表，读起来没那么有意思。Finbarr 坦言："我还是觉得中国实验室更愿意分享那种特别特别具体的细节。" 微软 MAI 则选择了更保守的配方路线。

### 7. 报酬最高的地方，往往也是你在做最有趣工作的地方

面对"梯子被抽走之前挤进实验室"的热潮，Finbarr 给出的判断是要区分短期套利和长期价值。他职业生涯里反复看到，高薪与有趣工作往往是重合的——关键是追随信念，在某个领域做到足够强。他回顾了在 DeepMind 与 AI2 的信念驱动式经历，并指出大实验室存在体量困境，需要多样化路线来对冲。

### 8. 开放环境市场报价离谱：一个环境十万美金

Finbarr 分享了他年初尝试购买 RL 环境的经历：一个 DoorDash 克隆级别的环境，前期成本约十万美金，每年维护费约五万，而且可能不包含提示词。Nathan 指出，真正值钱的是"我们知道这些提示词能提升某个基准测试"——那才能收高得多的溢价。算力、推理与 API 之间存在清晰的利润层级。

## 二、关键问答

**Q: 为什么 OMO3 后训练成推理模型如此困难、推出得晚？**
A: OMO3 的后训练复杂度已经逼近 AI2 组织能力的极限。现代后训练拼的不是单一技术，而是把算力和数据整合进一条工作流的能力，本质上是在整合组织架构图。所以 OMO3 作为推理模型推出得相当晚，且配方相对简单。Nathan 认为这对很多人来说都是一项重大成就。

**Q: InstructGPT 的三步法具体是什么？**
A: InstructGPT 的经典三步法是：先做 SFT（监督微调），再训练奖励模型（Reward Model），最后用 RL（强化学习，PPO）优化策略。这个框架奠定了后来几乎所有后训练配方的基础，Llama 系列、TULU 系列和 DeepSeek 都是在其上迭代演进的。

**Q: Llama 2/3 在配方上做了哪些迭代？**
A: Llama 2/3 引入了拒绝采样（rejection sampling）、DPO 以及多轮训练等改进。相比 InstructGPT 的单轮三步法，Meta 的做法更注重用拒绝采样筛选高质量样本，并引入 DPO 这种无需显式奖励模型的偏好优化方法，让配方更实用、更可落地。

**Q: TULU3 的简化配方说明了什么？**
A: TULU3 展示了在组织规模受限时，如何用一个相对简化但完整的配方（SFT、偏好优化、RL）达到不错的开源效果。它是"简单配方"路线的代表，也标记了配方趋同时代的分岔点——TULU3 之后，推理模型和 Agent 模型让简单配方不再适用。

**Q: DeepSeek R1 的配方有什么不同？**
A: DeepSeek R1 采用了 RL-first 与冷启动 SFT 的路线，把强化学习提到更靠前的位置，并用少量冷启动 SFT 数据稳定训练，从而激发模型的推理能力。这标志着后训练从"先对齐再强化"转向"以 RL 驱动推理能力涌现"的新范式。

**Q: 为什么 DPO 正在从主流配方中消失？**
A: 当后训练流程越来越精细、工业化，DPO 的边际收益就消失了，所以它从主流配方中淡出。但在配方粗糙、需要从零搭建的阶段，DPO 依然是算力效率最高的选择之一。Nathan 说："用 DPO 的人可能会被看不起，但如果你是想把一个配方从零搭起来，它仍然管用。"

**Q: 偏好调优是否被低估了？**
A: 有被低估的可能。虽然 DPO 作为具体算法在衰落，但偏好损失函数本身有时能带来惊人的提升。Finbarr 和 Nathan 都认为，偏好信号在配方中的作用不应被完全否定，关键是用在什么阶段、怎么用。

**Q: 多教师在线策略蒸馏的机制是什么？**
A: 在 RL 框架内，让正在训练的学生模型采样轨迹，再把这些轨迹路由给各个领域专家教师，用 KL 散度损失进行对齐。Finbarr 指出实现很直接：拿现有的 RL 配置，对学习者模型做一小套调整即可。DeepSeek V4 率先实践，MIMO Flash V2 命名了该术语。

**Q: 英伟达 Nematron 3 Ultra 揭示了什么问题？**
A: 英伟达发现，用差异很大的训练流程训练出的教师模型，无法通过简单在线策略蒸馏有效合并。教师和学生若用不同 SFT 数据训练，会习得不同推理行为，导致学生轨迹对教师而言是分布外数据，从而降低教师监督信号的质量和可靠性。

**Q: 分阶段蒸馏和收敛后蒸馏之争是什么？**
A: 这涉及蒸馏时机：是在训练过程中分阶段引入教师信号，还是等教师模型收敛后再做一次性蒸馏。两者各有支持者，争议点在于哪种方式能让教师信号更稳定、学生学得更扎实，目前业界尚无定论。

**Q: 微软 MAI 的配方选择为何保守？**
A: 微软 MAI 选择了一条相对保守的配方路线，没有激进地采用多教师在线策略蒸馏等新范式。这反映出大厂在投入巨大、试错成本高的背景下，更倾向于稳妥的、已被验证的做法，而非追逐尚未成熟的前沿技术。

**Q: 中国实验室在配方分享上有何不同？**
A: 中国实验室更愿意分享"特别特别具体"的细节，比如 KIMI K2.5 和 GLM5 都公开了温度调度、难度课程等可操作内容——尽管两者在温度调度上的说法正好相反。相比之下，英伟达的论文更像方法列表，可读性和可操作性都差一些。

**Q: 开源环境市场的现状有多疯狂？**
A: Finbarr 年初想买一个 DoorDash 克隆级别的 RL 环境，报价前期约十万美金、每年维护约五万，且可能不包含提示词。Nathan 指出真正值钱的是"我们知道这些提示词能提升某个基准测试"——那能收高得多的溢价，围绕 Tinker 风格 API 的商业模式因此充满争议。

**Q: 面对"挤进实验室赚钱"的热潮，该怎么选择？**
A: Finbarr 建议区分短期套利和长期价值。他职业生涯中反复看到高薪与有趣工作重合——关键是追随信念，在某个领域做到足够强。他还指出大实验室存在体量困境，需要多样化路线，个人应把"探索与利用"的取舍想清楚。
