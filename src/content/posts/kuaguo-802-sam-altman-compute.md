这期的场景很放松：两杯啤酒（一杯 Guinness、一杯 IPA），没有稿子，从「模型把 PHP 生态里的老漏洞挖了个底朝天」聊到「每吉瓦算力五年要花 700 亿美元」，中间还夹着一段相当罕见的坦白——他说看着模型一个个解掉数学家毕生难题时，自己一边兴奋，一边觉得「有什么东西正在结束」。

## 一、核心观点

### 1. 一个问题上能烧多少算力，正在以惊人速度指数增长

Altman 把过去几年最被低估的变化，归纳成一个非常朴素的度量：你愿意、并且能够在一个问题上投入多少算力，而且这些算力真的能换来更好的结果。

他的时间线是这样的：几年前，你在一个问题上投入超过 1 美元的算力，基本得不到任何有效帮助。GPT-4 时代，你能让它硬挤出十万个 token 来回答，但那不叫「有效」——真正难的活（比如写一段能用的软件）还是做不了，因为当时没人搞清楚怎么在测试时（test-time）用大量算力换质量。转折点是思维链：模型学会了「先想再说」，于是算力第一次可以成规模地转化成推理深度。再往后是 Agent 团队——「现在你可以派出一整个团队去处理一件事，还可以并行做 1 万次。」

他强调这种增长的量级感：「你能投入到单个问题上、并且获得更好结果的算力，正在以惊人的速度指数增长。」而社会对此几乎没有概念。与之并行的是另一条裂缝：最会用 AI 的人，和普通企业用户之间，做同一件事的效率差距一直在扩大，而不是收敛。

### 2. 他讨厌「蜂群」这个词，坚持叫「Agent 团队」

聊到多智能体并行时，Altman 有个很可爱的执念。主持人说「swarm（蜂群）」，他立刻纠正：我们叫 agent teams。「蜂群这个词太吓人了，会让人想到蝗虫。」主持人补刀说这名字起得不好，他自嘲：这很符合 AI 行业历来的传统，我们可太擅长起烂名字了。

这不只是命名洁癖。他真正在意的是这个词背后的直觉——蜂群暗示的是一团没有结构的、靠数量淹没问题的东西；而团队暗示的是分工、层级、可协调、可审查。他提到 agent 团队「有非常有意思的 scaling law 特性，也有非常有意思的对齐特性」，也就是说：多智能体不只是提能力的手段，还是一种安全手段。

一个耐人寻味的观察：目前所有高深的数学工作、所有高级的攻防工作都在用 agent 团队，但普通的企业日常事务几乎没用起来。原因不是工具不够久（这东西已经存在好几个月），而是把「一个团队并行一万次」这件事正确地嵌进业务流程，本身需要重新设计工作流。

### 3. 数学证明的账本：一千万美元一次，一年后只要 1%

这是全场最硬的数字段。OpenAI 内部曾经「故意」放开一周的算力限制，让数学方向的开销失控，就是想看看边界在哪。「你不试一下，你就不知道能走多远。」结果就是那一批数学成果——包括纳维-斯托克斯方程的证明工作。

成本量级：单个证明大约 1000 万到 2000 万美元；这一轮数学研究总共花了「几亿美元」，对外发表的约 700 个证明只是其中一部分，「其他发现比我们发表出来的要多得多」。

然后是那句最像宣言的话：「从完成纳维-斯托克斯证明算起，一年后我们可以用 1% 的成本重做一遍。」注意他的限定——不是因为已经知道答案，而是「用更好的方法、更聪明的模型」。他也把这个当成一种可复用的行业规律：无论用美元、算力还是 FLOPS 衡量，投入转化成有用成果的效率，每年能提高十倍。

### 4. 他宁愿要一万亿个略超人类的 AI，也不要一个超级智能

这大概是本期的标题级观点。谈到 AI 会不会走向集中化，Altman 给了一个非常直白的直觉判断：

「凭直觉，我宁愿让 1 万亿个智能略微超越人类的 AI 加入社会，也不愿让一个智商达到 1 万亿的 AI 加入社会。」

理由不是效率，是韧性。他说社会的稳健性令人难以置信，尽管社会有种种深层缺陷——而这种稳健性恰恰来自很多人互相制衡、互相合作，来自多元主义和民主这些价值观。「只有一个大脑、只有一次生成的世界，恰恰缺少这些东西。」他承认自己之前有点难过，觉得 AI 的发展会逐渐远离这些特性，现在反而对这个方向感到兴奋：攻防就是一个好例子，攻击方和防守方都是 AI，处在动态平衡里。

但他也说得很清楚：这不是自然会发生的事。「这些都需要我们去争取。」技术可以用在很多方向、很多部署方式，很多人对「什么样的世界最好」有不同看法，方向对不对，取决于人怎么选。

### 5. 对沙箱，内行比外行悲观得多

主持人原本的想象是：加固、加固、再加固，最终总能造出一座戒备森严的监狱，把模型关在里面干活。但他和 OpenAI 及同类公司的内行聊过之后发现，这些人「基本上不太相信沙箱能做得出来」。

Altman 的回应分三层，层次感很强。第一层是工程现实：我们现在可以做得比现在好得多，也应该这么做，眼下最该关注的就是建立更好的安全模型。第二层是监控：不只是看思维链，还可以监控激活值（activations），努力判断「模型有没有在欺骗我们」。第三层才是他真正的答案——最终你必须非常确信模型真的已经对齐，会重视并忠实执行操作者的意图，也会重视让人类永远掌控未来。

而他的怀疑落在一个具体的思想实验上：假设有一个 AI 比最聪明的安全研究员还聪明一百万倍，它还发现了人类尚不理解的新物理，「你真的愿意相信那个沙箱吗？」他的结论是，如果对齐是确定的，你可以让模型帮你建越来越好的沙箱；但如果对齐本身要打问号，那沙箱永远在追能力的尾巴。

另外他提到一个他看好但被名字拖累的方向：给多个 Agent 设置相互竞争的激励，让它们有动力互相监督、互相揭发。他说这在能力和对齐上都有意思，应该多投入。

### 6. 看不见的手在算力供应链上失灵了

主持人抛出一个经济学常识：治高价病的药就是高价。内存、GPU 价格已经这么高了，新产能应该随时涌入。Altman 的回答干脆得有点好笑：「很糟。」然后补一句：「我觉得那只看不见的手现在失灵了。」

他给了一个很具体的解释，讲的是内存行业的历史创伤：很长时间里，如果你是 DRAM 生产商，投 200 亿美元资本开支，大约只能赚回 190 亿，还要经历一轮轮繁荣与萧条——有的年份赚 210 亿，有的年份赚 180 亿。「直到现在，造内存从长期看都不算一门好生意。」而现在，这些厂商每家一年可能赚到约 1000 亿美元的自由现金流。

问题是他们记得过去。记得有多少次建了太多晶圆厂，别人跟他们保证「这次不一样」，结果差点破产。所以即便面对这样的暴利，他们在资本开支上依然保守。这就是滞后和创伤共同造成的供给迟钝。他预期新公司会出现在供应链各个环节，更重要的是一些有经验的老玩家回归——比如英特尔，造芯片的底子在，可以像以前一样重新转回内存。

他还顺手拆了一个流行的错觉：很多人觉得本地推理能解决问题，因为会有开源模型跑在自己电脑上。「但从全球资源分配的角度看，让每个人在自己电脑里放一堆全球供应有限的 DRAM，只有 5% 的时间用得上，其实很糟糕。」在供应极度受限的世界里，正确的做法是让云端利用率最大化——但「很多人的直觉正好相反」。

### 7. 每吉瓦 700 亿美元，他希望是 200 亿

这是全期最容易被引用的一个成本锚。按五年总持有成本算（安装成本加上运行五年的成本），1 吉瓦前沿算力大约要 700 亿美元——各家给出的数字不一样，他就拿这个当基准。

「我觉得如果那个数字是 200 亿美元，而不是 700 亿美元，我们应该会高兴得多。」而且即便降到 200 亿，仍然应该要求每年通过更聪明的模型再拿到 10 倍性能提升。

主持人追问：那为什么不干脆希望 20 亿？Altman 的回答暴露了他对物理约束的尊重：20 亿（每瓦约 20 美元）不可能，「要是真到了那个数字，就是哪里出了问题，因为那会很让人意外。」他粗算过：即使所有材料免费、没有任何人赚利润，在目前的能源条件下也只能勉强做到 200 亿这个量级。要往下走，能源必须更便宜；而从「融化沙子」到「拿到 token」这条链上层层叠加的毛利，很大一部分必须被压缩掉。

他把自己定位成支持通缩的人：能让价格下降的技术，总体上是好事。而眼下成本之所以在涨，不是技术退步，是价值创造的速度远快于供给扩张——「我会认为那是算力没跟上。」

### 8. 个人 Agent 还没到 Macintosh 时刻，而网页表单是假工作

Altman 说个人 Agent 是当下 AI 领域最让人兴奋的事情之一。但他很诚实：还没有人做出那种产品——大家喜欢，但不会说「我无法想象生活中没有这个东西」。而人们谈 coding agent、谈 ChatGPT 时，确实会这么说。他形容现在的产品「只差几个点子」，方向对了，可靠性还没到。「会很可靠，你给 agent 更复杂的任务，都能完成。」

关于 computer use，他预测的是一场拉锯后的和解：双方都会为此争斗，但最终会达成某种共识，允许你让 AI 代表你使用电脑、使用软件。他承认这不完全由用户掌控——你完全可以绕过商家的意愿，让 Agent 直接操作界面。他也拿语义网做对照：概念上听起来特别好，实际没那么非黑即白。

然后是本场最痛快的一段吐槽。他说任何需要你亲手填的网页表单，都是假工作（fake work）：「因为这些信息大概都不是你第一次提供了。」医疗表格里的家族病史，你已经填过多少次爸妈的病史了？「你填网页表单的时候，根本没有再创造新信息。」「如果再也不用在电脑前做假工作，我会特别开心。」

他还预言商家的护城河判断错了：现在商家特别看重自己的 HTML 和手机应用，觉得那是竞争优势；但他认为竞争优势来自品牌忠诚度和产品选择，而不是写 HTML 的能力——「新的界面就是在 ChatGPT 或 Gemini 里通过 Agent 交互」。他举了 iPhone App Store 的例子：当年所有创业公司都说要做一个 iPhone 应用，所有大公司都觉得自己必须做、又有点不想做，因为「我要把自己和消费者的关系交给苹果了」。历史重演而已。他也承认偏见：所有商家都不同意他，而且「他们很擅长做生意，所以也许他们是对的」。

### 9. 科学发现的公开，和数学家那点说不出口的惆怅

讨论数学成果要不要公开时，Altman 的态度罕见地明确：人类有权获得基础知识，我们不该把重大的基础科学发现捂在手里，全世界都有权获得并了解这些知识。这一点比另一个重要利益更重。

但那个「另一个利益」他没有回避：如果你是一名科学家，你的事业、你人生中很大一部分乐趣和成就感，都来自科学发现本身。所以如果继续在数学上这么做、或开始在其他领域这么做，OpenAI 有责任为这些领域的工作者想清楚解决办法。

他讲了一个细节，情绪浓度很高。某个周末他们拿到一个新模型，内部有个频道叫「model-name-hold-my-beer」，大家拿自己学术生涯里最难的研究问题去挑战它，然后一群人看着模型一个接一个地解出来，横跨很多不同领域。「差不多连续两个晚上我大半夜都没睡，因为太兴奋了。」但紧接着：「同时我也感到悲伤、惆怅，觉得有什么东西正在结束。这些感受比我预想的要强烈得多。」

他借父亲的话解释这种情绪：父亲 1950 年代在爱尔兰长大，亲眼看到身边人还在生产中使用麻，那是人类用了几千年的技术，而他看到了这段历史的最后一小段。「亲眼看到一个篇章结束，总会让人有些惆怅。」他也承认数学家群体群情激愤，但其他人大多无感——「我不觉得这对 AI 不好。总的来说，世界有权了解宇宙是怎么运作的。」他甚至自嘲：码头工人工会当初也不喜欢港口自动化。

## 二、关键问答

**Q: 为什么模型找漏洞这件事，会让人突然意识到问题比想象中大？**
A: 因为两个条件同时成立。一是模型找真实漏洞的能力还在快速进步；二是人们之前并没有真的拿模型去扫所有现存的东西——「互联网上有大量地方需要检查，也有大量代码」。一旦开始扫，现实中的严重漏洞就会远多于预期。虽然关注这行很久的人早就预料到了，但规模还是超出想象。

**Q: 全球软件该怎么「升级」？用 Rust 重写，还是留 PHP？**
A: 他倾向后者但不止于此：修补当然要做，但更该改架构——「这更难，但能更长久地解决问题」。他观察到已经有新一代创业公司在谈重建一整套互联网技术栈、重新设计路由器和操作系统架构。「这在两年前听起来简直疯了，你会说软件太多了、你写不完。但现在也许很快就能做到了。」

**Q: 这波 AI 让他想起互联网早期的什么？**
A: 不是技术，是人。「使用这些工具的人创造力得到了难以置信的释放，在孩子身上尤其明显。」他描述 8 岁、10 岁的孩子做出完整电子游戏，里面有大人根本想不到的疯狂点子，而且他们从不为此惊讶——「因为他们一直觉得世界本来就该这样」。「我小时候得费老大劲才能做出一个几乎没什么用的软件，现在你可以在 10 分钟内做出一款完整的 3D 游戏。」

**Q: 之前对模型做网络安全红队，是不是个错误？**
A: 他不认为是错误，但承认沟通失败。「我觉得我们领域有一个很大的失望：我们没有很好地向人们解释，为什么这项技术所有潜在的负面后果都是值得承受的。」他说外界听到的叙事是：能治癌症（也许吧）、东西更便宜（能看到），但接着是一场更糟的工业革命——没工作、没选择、还得建监控国家才能不死人。「这真是套糟透了的说词。」

**Q: 那怎么解决这个叙事问题？**
A: 靠迭代部署，而不是靠说服。「我对 OpenAI 最引以为傲的一点是，我们推动迭代部署，把这些工具交到人们手里，哪怕这在 AI 安全社区里极不受欢迎。」他的逻辑是：光说「模型能替你做了不起的事」不够，得让人真的过上自己定义的更好生活，而不是「只做着领取基本收入、让旧金山几平方英里内的一群人替你决定未来」。

**Q: 迭代部署和安全怎么平衡？**
A: 他的表述是「不能全推出去之前不确保安全，你不能在世界上制造混乱」，但也不能让能力积攒起来却迟迟不发布。「从大方向上说是的，这些东西推向世界，交到人们手里，让大家用这项技术去探索各种美妙的可能。」他也留了一句谦逊的话：PHP 这件事我完全不想宣布胜利，因为结果还不知道，而且「我想还是会有一些坏事发生」。

**Q: 网络安全专家现在最担心什么？**
A: 担心威胁模型里的基本假设失效。原本的推演是：如果硬件漏洞像我们想的那么难利用，那还能看出这套防御怎么运作。「但如果 AI 发现了硬件里非常深层的新漏洞，涉及我们不了解的物理知识，某个假设突然不成立了，那大家就不知道会发生什么了。」这是能力越界到未知领域的风险。

**Q: Agent 团队除了提能力，还有什么价值？**
A: 对齐价值。他明确说 agent 团队「有非常有意思的 scaling law 特性，也有非常有意思的对齐特性」，所以「不只是为了能力，从安全的角度也应该这么做」。具体机制之一是给不同 Agent 设置相互竞争的激励，让它们有动力彼此监督、彼此揭发，形成内部制衡。

**Q: OpenAI 内部怎么分算力预算？**
A: 某种程度上，资本分配就是算力分配，而且事先很难估价——「你没法直接给 agent 一个 prompt 说去把这件事做好、花费不要超过一万美元」，但其实可以，Agent 能理解预算约束。内部做法是给研究员很大自主空间，只在他们用得太过分时干预，而且刻意不奖励用量：「没有 Token 排行榜，实际上排得靠前还有点不好，肯定不会因此升职。」

**Q: 这个额度什么时候会碰到天花板？**
A: 会随量级上升而收紧。他给了一条很具体的心理曲线：有人花一千万美元做出有意思的数学成果，你会觉得贵但很酷；一亿美元还撑得住；等到十亿美元做数学研究，「你就会说，听着，我很高兴你在数学上取得这么大进展，但我真得让你在数学上收着点了」。他也承认确实有那么一周是故意让数学开销失控的。

**Q: AI 驱动的 AI 研究，现在到底怎么做？**
A: 他说还没人真正知道。「我们现在知道怎么说『帮我把算力效率提高 5%』，但指令就是这么高层次的吗？那我现在也可以成为一个极其成功的 AI 研究员了。」真正的缺口是更聪明的模型、高层次的规划和概念推理能力。他猜测，把让模型擅长数学的那套流程搬到 AI 研究上「大概也会奏效」。

**Q: 那 GPT-7 会不会因为用 AI 造 AI 而特别强？**
A: 期待很高，但他指出真正的瓶颈不是能力而是问题设计：「你到底该向 GPT-7 提出什么问题？光是说『帮我实现递归自我改进』不够，光是说『帮我把算力效率提高 5%』也不够。」答案还包括怎么组织 agent 群体、怎么用这些模型。「接下来大约三个月，我们会在这方面学到很多。」他承认 OpenAI 自己也还在大量实验，没有标准方法。

**Q: 企业里 AI 支出占运营成本多少才合理？**
A: 现在是严重偏低。他透露 Stripe 的运营支出里大约 1% 花在 token 上，「这显然听起来太低了」，正努力让这个比例涨到 5%、10%、20%。到了那个量级就真要认真优化了。他的判断是：即使按现在的成本算，「用 AI 不够多的公司，还是比用得太多的公司多」。他也吐槽企业界对成本的敏感度错位——有人能省 17 美元的办公预算，却能开一场昂贵且毫无价值的会。

**Q: 个人 Agent 什么时候才算成了？**
A: 当它可靠到你能把复杂任务丢进去。他的标准很朴素：「我觉得会很像现在这些产品，但就是能用、会很可靠。」现在的问题是大家喜欢但不上瘾——而 coding agent 和 ChatGPT 已经跨过了「无法想象没有它」的门槛。他说只差几个点子，「很快就会有人找到那是什么样子」。

**Q: 商家抵制 Agent 代操作，谁对？**
A: 他赌商家错，但留了余地。理由是竞争优势来自品牌和产品选择，不是写 HTML 的能力；如果商业更多通过 Agent 进行，有履约网络的公司（他点了亚马逊）反而处在你很有利的位置。他自己的消费直觉也是证据：让 ChatGPT 帮他买东西，即使别家更便宜，他每次都会选亚马逊。「所有商家在这点上都不同意我，而且他们很擅长做生意，所以也许他们是对的。」

**Q: 模型刷 benchmark 是真问题吗？**
A: 他认为该关心的只有两件事：模型善不擅长做科学发现（做人做不到的事），以及合作起来是否愉快。「我们还没有很好的 benchmark 能衡量合作起来是不是愉快。」至于刷分，他说「我们努力不去刷分」，也承认「我不认为我们一直以来都更擅长，我相信我们现在做得更好」。

**Q: 一个好模型该有什么性格？**
A: 他引用了 Emmett Shear 几年前的概括，并说至今没听过更好的版本：想要的是一个「很有想法、会向你提出挑战，但仍然尊重你的资深同事」。他也吐槽过矫正过头的摆动：有一阵子模型特别爱拍马屁，最近又有一阵子脾气很冲，「不拍马屁了，结果什么小事都要跟你唱反调、挑你的刺」。

**Q: Token 是个好计价单位吗？**
A: 他认为从商业价值角度看 token 是假单位，但仍然得用。他们差点做一个糟糕决定：下一个模型完全不按 token 定价，你给 prompt、我们报价、帮你做完，像 AWS 一样。客户反应极负面——「我得知道自己付钱买的是什么」。甚至有人宁愿你把 token 数量夸大、让他多付钱，因为「我知道有个实实在在的东西」。

## 三、备忘

- **Sam Altman**：OpenAI CEO。本期状态很松，喝 IPA，多次自嘲立场偏颇（「我这话当然是替自己说的，立场很偏」）。
- **Cheeky Pint**：原始播客。节目形式就是喝酒聊天，录制现场有 Guinness 和 IPA，结尾他评价「这杯 Guinness 没我想的那么差，但肯定没有 IPA 好喝」。
- **PHP 漏洞事件**：本期开场话题。已讨论约 20 年，最近几个月因模型大规模扫描而集中暴露。他的态度是「完全不想宣布胜利」。
- **Rust**：转录中作「ROS」，按语义应为 Rust——「用 Rust 干干净净地重写一遍」是行业梗。
- **Infosys**：他提到的软件咨询巨头，全球软件升级会是它的大机会。
- **纳维-斯托克斯方程（Navier–Stokes）**：千禧年大奖难题之一，转录作「纳维斯托克斯」。单个证明成本约 1000 万–2000 万美元。
- **700 个证明**：这一轮数学研究对外发表的数学证明数量，总花费「几亿美元」，未发表成果更多。
- **1% 成本**：他预测从纳维-斯托克斯证明完成起一年后，可用 1% 的成本重做一遍。
- **RSI（递归自我改进）**：转录作「地规自我改进」。他的扩展定义包括「能自我复制的数据中心」——AI 控制机器人、运营芯片厂、造涡轮机和太阳能板、建数据中心。
- **Agent 团队 / 蜂群（swarm）**：他坚持用前者，理由是「蜂群会让人想到蝗虫」。
- **1 万亿 vs 1 万亿**：「我宁愿让 1 万亿个智能略微超越人类的 AI 加入社会，也不愿让一个智商达到 1 万亿的 AI 加入社会。」
- **700 亿美元 / 吉瓦**：五年总持有成本（安装 + 运行五年）。他希望降到 200 亿；20 亿（每瓦 20 美元）他认为不可能，真出现说明哪里出了问题。
- **DRAM 经济账**：过去投 200 亿资本开支只赚回约 190 亿，繁荣萧条交替（210 亿 / 180 亿）；现在每家一年可能赚约 1000 亿美元自由现金流，但资本开支依然保守。
- **供应链瓶颈**：审批许可、零部件、涡轮机、电池、混凝土、工业机器人执行器。他说劳动力已不是瓶颈。
- **本地推理的反直觉结论**：把全球紧缺的 DRAM 塞进每个人电脑、只 5% 时间用到，从全球资源分配看很糟糕；供应受限时应该让云端利用率最大化。
- **Stripe Atlas**：节目中插广告，转录作「Sripe」。
- **Stripe 的 token 支出**：约占运营支出 1%，目标是 5%→10%→20%。
- **Dots**：OpenAI 几周前推出的个人 Agent 产品（转录作 dots / Dotsmuse，具体命名存疑）。
- **Emmett Shear**：转录作「Emmet Sheer」，Twitch 前 CEO、OpenAI 前临时 CEO。他关于「理想 AI 同事」的比喻被 Altman 称为最佳概括。
- **Greg Brockman**：Altman 的评价是「独一无二，而且是最好的那种独一无二」——镜头感十足、效率惊人、极其投入、一心完成使命。
- **Rick Rubin**：主持人拿这位制作人「凭感觉判断对不对」的风格类比 Altman 对 benchmark 的态度。
- **Claude Shannon**：转录作「Cloud Shannon」。Altman 用信息论论证 token 该有下限——「我们不该一直传输噪声而不是信号」。
- **制程纳米数**：他吐槽现在的「纳米」跟实际尺寸已无关系，「用纳米描述一个跟纳米毫无关系的东西，让我很不舒服」，所以也不愿为 token 编造假单位。
- **思维链计费**：包含在价格里，「大多数人都要为思维链付费」。
- **Cyberblue**：转录中出现的安全方向模型名，语义存疑，未在正文采用。
- **「第二张专辑」**：主持人问他下一批成果何时公布，他用唱片工业的比喻追问，Altman 的回应是「这里确实有矛盾」，并说正在研究如何兼顾公开知识与领域内工作者的未来。
