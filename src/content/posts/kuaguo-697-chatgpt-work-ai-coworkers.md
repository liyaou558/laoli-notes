## 一、核心观点

**1. AI 产品的第三个时代，是拥有一个常驻 AI 同事。**
Tara 将 AI 产品的发展分为三个阶段：最初是 Chat（聊天），接着是与 Agent 协作（调用一次性任务），而下一阶段则是与一个长期存在、能够持续推进工作的 AI 同事共事。这个 AI 不只回答一次问题，而是像团队成员一样持续工作、接受反馈，甚至与其他人的 Agent 协同完成任务，形成多人协作的 Agent 群聊。

**2. AI 时代，PM 从划桨者变成掌舵者。**
当 Agent 可以承担越来越多的具体执行工作，人的角色不会因此消失，而是上升到更高的抽象层：确定目标、判断方向、解释反馈，并决定产品与世界应该朝哪里发展。执行可以交给 Agent，但方向感和最终决断仍需要人来提供，未来的工作会越来越像掌舵而不是划桨。

**3. 最危险的产品开发方式，是押错模型时间点。**
AI 产品不能只按今天的模型能力设计，否则很快会过时；也不能按一年后的想象设计，因为那同样脱离现实。真正可行的节奏是紧贴研究进展，在两到三个月的时间窗口里持续调整产品架构与体验——「如果你按模型现在的水平去开发，你会失败；按一年后的设想开发，你也会失败。」

**4. AI 让野心成为新的竞争壁垒。**
当简单任务变得人人都能完成，人与人、公司与公司之间的差距就不再主要来自执行能力，而来自对可能性的想象。最会使用 AI 的人不只是自动化重复劳动，而是借助 AI 把过去无法实现的想法快速变成原型、网站、模型和产品——AI 把普通人变成「独角兽人才」，真正的瓶颈不是能力而是想象力。

**5. 人类的价值，从亲自执行转向承担责任与表达主见。**
Agent 可以完成大量工作，但最终必须有人判断结果是否正确、质量是否足够、是否符合目标，并为产出承担责任。除此之外，产品中的作者性、品味、艺术表达，以及人与人之间的关心与连接，仍然是难以被简单自动化的部分。Tara 的答案包括责任、判断、表达、品味与人与人之间的连接。

**6. 「写作是思考」不能外包，「写作是汇报」可以自动化。**
Tara 将工作写作分成两类：用于整理和形成自己观点的写作，以及用于总结、汇报和格式转换的写作。后者可以尽可能交给 AI，但前者正是人训练判断力、澄清思路和发现问题的过程，不能完全交给模型——「以写作为思考，是我永远不会自动化的。」

**7. 知识工作必须看见推理过程，而不只是最终结果。**
写代码可以通过测试判断结果是否运行正确，但知识工作往往不能只看一份漂亮的 PPT 或报告。用户需要了解 AI 使用了哪些信息、如何推理、引用了什么来源，才能真正判断结果是否可信。因此未来的 AI 产品必须成为协作者，而不是只交付答案的黑箱。

**8. 完成好过完美，反馈闭环比上线前打磨更重要。**
在模型和产品能力高速变化的时代，过度追求上线前的完美可能意味着错过最重要的学习机会。更有效的做法是尽快把产品交给用户，观察真实使用方式，识别哪里行不通，再快速迭代——「当你非常确信它具有颠覆性的时候，把产品交到用户手里远比追求完美要好得多。」

## 二、关键问答

**Q：AI 产品发展的三个阶段分别是什么？**
A：第一阶段是 Chat，用户与 AI 以对话方式交互；第二阶段是与 Agent 协作，把一次性任务交给 AI 去执行；第三阶段则是与一个长期存在、能够持续推进工作的常驻 AI 同事共事。第三个时代里，AI 不再只回答一个问题，而是像团队成员一样持续工作、接收反馈，并与其他人的 Agent 协同完成任务。

**Q：在 OpenAI 内部，人们如何快速做产品实验？**
A：OpenAI 的文化让每个人都像创始人一样运作，强调从理论推演转向快速实证。与其写长篇战略文档，不如多产出、靠实证说话。PM 的核心工作是定义问题、验证假设、跑通反馈闭环——在模型能力快速变化时，用小步快跑的方式尽快确认方向是否可行，而不是闭门打磨完美方案。

**Q：为什么 PM 必须从「划桨」转向「掌舵」？**
A：当 Agent 能承担越来越多具体执行工作，人的角色并非消失，而是上升到更高抽象层。掌舵意味着确定目标、判断方向、解释反馈，并决定产品与世界应朝哪里发展。执行可以交给 AI，但方向感与最终决断仍需人来提供，这恰恰是知识工作者未来不可替代的价值所在。

**Q：Agent 如何才能成为「真正的同事」，而不只是工具？**
A：关键有三点：一是与长期存在的 Agent 协作，而非用完即弃；二是从一对一 Agent 走向多人协作的 Agent 群聊，让人与多个 AI 一起推进项目；三是慢起飞、逐步建立信任，让 Agent 承担越来越多的工作。同时，数据访问、云基础设施与可靠性同样关键，缺一不可。

**Q：Chat、Work 与 Codex 到底有什么区别？**
A：Chat 面向日常对话式提问，Work 则更侧重把 AI 当作持续工作的产品环境，Codex 则聚焦代码与工程任务。三者都隶属于 OpenAI 的产品体系，Tara 与工程经理 Andrew Ambrosino 负责的正是 Codex 与 ChatGPT Work。最终这些模式可能走向融合，把 Agent 能力带给十亿 ChatGPT 用户。

**Q：产品应该面向现在还是未来的模型来设计？**
A：两者都不对。如果按模型现在的水平开发，产品很快就会过时；如果按一年后想象的模型水平开发，又会脱离现实。正确节奏是紧贴研究进展，在两到三个月的时间窗口内持续调整产品架构与体验，让产品始终略超前于当下能力、又不至于过于理想化。

**Q：AI 如何把普通人变成「独角兽人才」？**
A：当简单工作被自动化，人与人之间的差距不再来自执行能力，而来自想象力和野心。最会使用 AI 的人借助它把过去无法实现的想法快速变成原型、网站、模型和产品，从而以小团队甚至单人的力量做出过去需要整个团队才能完成的事情。真正的瓶颈不是能力，而是想象力。

**Q：当工程师、设计师和 PM 的边界开始消失，人类还剩下什么价值？**
A：Tara 的答案是责任、判断、表达、品味、人与人之间的连接，以及决定未来应朝哪个方向发展的主见。Agent 可以完成大量工作，但最终必须有人判断结果是否正确、质量是否足够、是否符合目标并为之负责，这些非对称优势是难以被自动化替代的。

**Q：「写作是思考」和「写作是汇报」有什么区别？**
A：用于整理和形成自己观点的写作，是人训练判断力、澄清思路、发现问题的过程，Tara 表示「以写作为思考是我永远不会自动化的」；而用于总结、汇报和格式转换的写作则完全可以交给 AI 完成。区别在于前者塑造认知，后者只是信息的重组与呈现。

**Q：为什么知识工作需要看见推理过程，而不只是结果？**
A：写代码可以通过测试判断结果是否运行正确，但知识工作往往不能只看一份漂亮的 PPT 或报告。用户需要了解 AI 使用了哪些信息、如何推理、引用了什么来源，才能判断结果是否可信。因此未来的 AI 产品必须成为协作者，而不是只交付答案的黑箱。

**Q：找到 PMF（产品市场契合）是可复制的打法，还是玄学？**
A：Tara 在 Sutter Hill Ventures 的经历告诉她，找到 PMF 不是玄学，背后存在一套可复制的打法。关键在于产品与营销的契合要早于产品本身，并在早期就建立验证假设的闭环。与其追求一次性完美，不如尽快把产品交到用户手里，观察真实使用方式再快速迭代。

**Q：Tara 自己如何用 AI 工作？**
A：她提到会在工作中用 AI 建网站与做可视化，把想法快速落地成可运行的原型。她的经验是：只要你有野心和方向感，AI 就能把执行成本降到极低，让人把精力集中在定义问题、判断方向与承担最终责任这些更高层的工作上。
