## 一、核心观点

### 持续学习才是正常的思考方式，是 AI 领域把它当成了特殊概念
Rich Sutton 开场就抛出一句「我不怪，这个领域才怪」。他的逻辑很简单：所有学习本质上都是持续的——我们一直在行动，一直在学习，这本来就是一个智能体最自然的运作方式。之所以有人觉得他「怪」，是因为主流 AI 领域把「持续学习」单独拎出来当成一个特殊、难啃的课题，仿佛它是某种反常的东西。Sutton 反过来说：真正反常的是那种「训练完就冻结」的做法——一个系统在预训练结束之后就不再改变，这在自然界里找不到任何对应物。

### 《苦涩的教训》的本质：别让人类知识带偏方向
2019 年写下《苦涩的教训》，Sutton 的核心主张是：在 AI 的历史上，凡是依赖人类知识、手工编码特征的方法，长期来看都会被「用更多算力、更多搜索、更多学习」的通用方法碾压。他反复强调，最苦涩的一点就在于：我们自己觉得很聪明、很得意的领域知识，最终反而成了阻碍。把人类对世界的理解硬塞进系统里，短期有效，长期却是天花板。这一观点放到今天看，几乎是对「别被人类知识带偏」最直白的一次预警。

### 大语言模型既是《苦涩的教训》的正面例子，也是反面例子
Sutton 认为 LLM 两面性并存。正面在于，它把「计算规模扩展」这条路走到了极致，直接吞下整个互联网，没有依赖太多手工特征，这正是《苦涩的教训》所推崇的方向；反面在于，它最终还是被人类知识限制住了——互联网是有限的，而世界比互联网上的一切都要大得多得多。换句话说，LLM 证明了「scale + 通用方法」的力量，但也暴露了「训练数据本身是人类知识产物」这一根本局限。

### 合成数据是一个「大错误」
Sutton 直言合成数据是「大错误」。他的质疑分两层：第一，谁来判定什么样的合成数据是好的？这需要一个人类专家来把关，而这个「人类专家」本身就是瓶颈——你绕了一圈，又把人类知识请了回来。第二，更根本的是，世界无限复杂，任何对世界的模拟都渺小得可怜。你用一套有限的规则生成数据，等于在一个被阉割的世界里训练智能体，它永远学不到真实世界的复杂度。Sutton 的结论是：合成数据无法替代真实经验。

### 大世界假说：世界远比互联网大得多
这是 Sutton 与 Khurram Javed 共同提出的核心命题——「大世界假说」（The Big World Hypothesis）。互联网虽然庞大，但只是真实世界的一个极小切片：真实世界里有物理、有交互、有时间、有后果，而互联网只是人类用文字和图像对世界的二手转述。大世界假说主张，真正的智能必须直面这个比互联网大得多的世界本身，而不是停留在人类已经写下来的那一层。这也解释了为什么合成数据注定不够：任何模拟都只是真实世界的一个无穷小的影子。

### 大语言模型不是经验型学习者，部署后权重永不改变
Sutton 一针见血地指出：LLM 的权重永远不会变。预训练与后训练结束之后，模型就不再学习了；你可以给它更多上下文，但模型本身已经停止学习。一个真正在环境中持续行动、持续接收反馈、持续更新自己的智能体，才是「经验型学习者」。有趣的是，他举的反例是 Cursor 和 Tab 这类产品——它们因为持续更新权重、持续吸收用户反馈，反而是「持续学习」的更真实例子，尽管它们的底层仍是 LLM。

### 我们卡在了一个局部最优里
Sutton 认为，大实验室已经被产品绑得太死，无法去走一条「事情会先变差」的路。任何新范式在变好之前，几乎不可避免地会先变差——而现有产品的用户、股价和商业承诺都不允许这种倒退发生。于是整个行业被锁在 LLM 这个局部最优里：所有人都知道还有更大的空间，但没有人敢承受「先变差」的代价去探索它。这正是他创办 Oak Lab、跳出主流叙事的原因。

### 语言大概只占智能的 20%
Sutton 给出了一个颇为挑衅的估算：大语言模型大概只占智能的 20%，或者四分之一。他的意思是，智能并不只是流畅的语言运用能力——还有太多别的东西：感知、行动、因果、长期记忆、对物理世界的建模、持续适应环境的能力。语言是智能最显眼的一层，但也是最容易被误认为「全部」的一层。把 LLM 当成智能的全部，恰恰是一种「被人类知识带偏」的当代版本。

## 二、关键问答

**Q: 为什么在 AI 寒冬时期押注强化学习？**
A: Sutton 看重的不是当下热不热，而是方向对不对。他认为强化学习研究的是「智能体如何在环境中通过行动和反馈持续学习」，这更接近智能的本质。寒冬只是资本和关注度的退潮，不代表问题本身不值得做。他和 Khurram 都是那种「问题对了就不在乎周期」的人。

**Q: 2003 年与癌症搏斗的经历对他有什么影响？**
A: 这段经历让 Sutton 对「时间」和「优先级」有了更清醒的认识。面对生死，人会本能地追问：什么才是真正重要、值得把有限生命投入进去的问题？对他来说，答案就是持续学习这个根本性的方向，而不是追逐短期的研究热点。这也是他后来敢于长期押注冷门方向的心理底色。

**Q: 2019 年写下《苦涩的教训》的契机是什么？**
A: Sutton 观察到 AI 领域几十年来反复出现同一种模式：研究者倾向于把自己辛苦得来的知识编码进系统，短期内效果不错，长期却被「更多算力 + 更多学习」的通用方法超越。他写下这篇文章，就是想用一个「苦涩」的标题警醒整个领域：别把人类知识看得太重，规模和学习才是真正持续赢家的关键。

**Q: 谁来判定合成数据的好坏？**
A: Sutton 认为这正是合成数据的死穴。要判断一份合成数据是否「好」，你需要一个人类专家来把关——而这个人类专家本身就是瓶颈所在。也就是说，合成数据看似摆脱了人类数据，实际上在质量判定环节又把人请了回来。更糟的是，人类专家能判断的只是「像不像人类知识」，而不是「像不像真实世界」。

**Q: 自动驾驶模拟器的问题出在哪里？**
A: 问题在于「人类在循环里的瓶颈」。模拟器本质上是人类对真实驾驶场景的简化复刻，它的复杂度和真实世界差了无数个数量级。用模拟器训练出来的系统，只能应对模拟器里出现过的那些情况；而真实道路上的长尾场景是无穷无尽的。模拟器越精细，越依赖人类去标注和构建，瓶颈就越明显。

**Q: 为什么说大语言模型不是经验型学习者？**
A: 因为 LLM 在预训练与后训练结束之后，权重就固定了，模型本身不再学习。它虽然可以在推理时「看起来」很聪明，但那是静态权重的一次性前向计算，不是通过与环境交互、接收反馈来更新自己。Sutton 对比说，Cursor 和 Tab 这类持续更新权重的产品，反而更接近「持续学习」的真实例子。

**Q: 持续学习的算法缺口是什么？**
A: Sutton 指出，持续深度学习是一个长期被忽视的算法缺口：主流深度学习假设「训练完就部署、部署后不变」，而持续学习要求系统在部署后仍然不断更新，且不能遗忘之前学到的知识（即灾难性遗忘问题）。这个缺口不是工程问题，而是需要新的算法范式来填补。

**Q: 解药是什么？**
A: Sutton 与 Khurram 给出的具体技术路径包括「持续反向传播」（Continual Backpropagation）和「步长优化」（step-size optimization）。持续反向传播让网络在部署后仍能继续更新梯度；步长优化则是让系统自动调整每个参数的学习步长，从而在「学新东西」和「不遗忘旧东西」之间取得平衡。

**Q: Oak Lab 最有野心的目标是什么？**
A: 拥有「完整跨度的知识」。Sutton 描述的理想智能体，是一个能持续学习、形成抽象、并保持自洽的系统——它不会像 LLM 那样被冻结在某个时间点，而是像生物一样，在整个生命周期里不断吸收新经验、更新对世界的理解。这种「完整跨度」的持续成长，是 Oak Lab 想实现的终极形态。

**Q: 为什么说新范式在变好之前会先变差？**
A: 因为任何全新的范式一开始都不成熟：它可能比现有系统更慢、更不稳定、表现更差，需要大量迭代才能越过拐点。大实验室被产品、用户和商业承诺绑得太死，无法承受这种「先变差」的过渡期。于是大家集体留在 LLM 这个局部最优里，不敢走出去探索更大的空间。

**Q: 如果一切顺利，Oak Lab 会变成什么样？**
A: 按照 Sutton 的判断，这件事「触手可及」，大约五到十年内就能看到实质进展。如果一切顺利，Oak Lab 会成为「持续学习智能体」这一新范式的发源地，产出一个能像生物一样持续成长、不断吸收真实世界经验、并保持自洽的智能体，从而跳出当下 LLM 的局部最优。

## 三、备忘

- **《苦涩的教训》（The Bitter Lesson）**：Rich Sutton 2019 年发表的著名短文，主张「更多算力 + 通用方法」长期胜过「人类领域知识 + 手工特征」。
- **大世界假说（The Big World Hypothesis）**：Rich Sutton 与 Khurram Javed 提出的核心命题——真实世界远比互联网大得多，合成数据无法替代真实经验。
- **灾难性遗忘（Catastrophic Forgetting）**：神经网络在学习新任务时遗忘旧知识的经典问题，是持续学习的核心障碍。
- **持续反向传播（Continual Backpropagation）**：让网络在部署后仍能持续更新梯度的算法方向。
- **步长优化（Step-size Optimization）**：让系统自动调整每个参数的学习步长，以平衡「学习新知识」与「保留旧知识」。
- **Oak Lab**：Rich Sutton 与 Khurram Javed 创办的实验室，目标是打造能持续学习、形成抽象、保持自洽的新一代智能体。
- **Khurram Javed**：Rich Sutton 的长期合作者，持续学习方向的共同推动者。
- **主持人 Sonya Huang 与 Alfred Lin**：来自 Sequoia Capital，本集源自其 Training Data 播客。
- **Rich Sutton**：阿尔伯塔大学强化学习研究的核心人物，强化学习奠基人之一。
