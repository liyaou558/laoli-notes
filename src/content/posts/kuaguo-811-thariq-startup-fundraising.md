## 一、核心观点

### 融太多钱，等于提前抵押掉了所有退出选项

Thariq 的公司做了五年，产品是一个可以在线玩《龙与地下城》这类桌游的平台。A 轮融了大约 1500 万美元，而团队只有七八个人——在游戏行业，这个人数配这个金额是相当罕见的。他的复盘非常直白：融资规模远远超出了当时已经证明的业务进展所能支撑的水平。后果不是"账上钱太多花不完"，而是结构性锁死。如果想把公司卖掉，"我们融了这么多钱"这一条就会让收购方退避三舍，因为估值锚已经被抬到一个业务撑不起的位置。换句话说，超额融资买到的不是更多时间，而是更少的可能性。他最后的选择是把剩下的钱退回去，关掉公司。这在创投圈是极少见的动作，但对一个已经认清"这笔钱买不来对应结果"的创始人来说，反而是最干净的处理方式。

### 融资带来的第二重伤害，是"我已经做成了"的幻觉

比结构性锁死更难察觉的是心理层面的副作用。Thariq 说，融太多钱会让你觉得自己已经做出了点成绩，但其实并没有。钱到账的那一刻，市场、投资人、甚至创始人自己的叙事都会滑向"这家公司成了"，而真实的产品与用户进展还停在原地。这种错位会在后续每一个关键决策上放大：你会用"我们已经是 A 轮公司"的标准去招人、租办公室、定路线图，而不是用"我们现在的证据支持什么"去决定。对一个只有七八个人的团队来说，1500 万美元放进账户，本身就是一种持续输入的麻醉剂。他把这层说得很轻，但它其实解释了为什么很多融资顺利的公司反而死得更慢、更贵。

### 实验室正在变成人才黑洞，光环被社交媒体二次放大

谈到 Anthropic 这类实验室时，Thariq 用了一个很重的词：人才黑洞。他承认自己多少也受这套叙事影响——"我可以自己开公司，也可以加入一家实验室"，最后他选了后者。他把当下的情形类比成当年的谷歌，但认为现在更夸张，因为科技行业的人更多、讨论的人更多，而且 Twitter 上还有一层刻意营造光环的意思。他同时给了一个降温的观察：每次进入一个新机构，比如 MIT 或者 Anthropic，他的感受都是"这些人很聪明，但他们也只是人"，Twitter 上有很多人更聪明、也在做非常有意思的工作。崇拜到某个程度就不健康了，而"AGI 是最重要的事，所以我要去为它做贡献"这句话，恰恰是最优雅的劝退话术。

### "打不过就加入"看起来很理性，但创业是靠势头推进的游戏

主持人问：OpenAI、Anthropic 每发一个产品，大家就说这要把初创公司全杀光了，站在早期投资那一边，过去一年看到了什么？Thariq 的回答绕回了自己：Anthropic 不久前也只是家初创公司，当时看起来同样没什么希望——OpenAI 已经存在，谷歌似乎拥有所有的钱和所有的芯片。所以关键不是理性推演，而是不要想太多。他的原话是，创业是一场靠势头推进的游戏，你想得太多，基本上就会自己退出这场游戏；你只能不断去找产品与市场的契合点，然后在此基础上继续往前走。任何一个过于理性的人都会得出"不可能打败这些人，那还不如加入他们"的结论——而这正是大部分人停下来的地方。

### 勇气比天才更稀缺

这是整期节目里最像金句的一句。Thariq 说旧金山有很多有天赋的人，但有时候缺少勇气——敢说"我要试一试"，而不是去加入某家实验室。他以 Instinct 为例：找一个非常简单的想法，认真对待，然后全力去做，做得比任何人都好，这就已经在当下的文化潮流里占到了一席之地。他认为大多数创始人会觉得光是这样就已经非常成功了。换句话说，可做的有意思的想法还有很多，门槛不是智力，而是"专注解决问题 + 有能力 + 一点勇气"这个组合。反过来，他也很清楚自己现在的位置：离开 Anthropic 之后按这套逻辑就该去创业——"对，我是应该"，或者，也可以来上这档播客，这也算一种展现勇气。

### 播种与收获：内容来自那些还没被外包掉的苦差事

他讲了一个关于创作者的结构性困境：你得先去做有意思的工作，然后才能讲出来。而真正有意思的工作里，大部分是无聊、烦人、重复的苦差事。一旦你出名了，或者把这些苦差事雇给别人做，你就没有素材了——你的人生变成了"当名人"，而不是"在做有意思的事"。音乐人身上也能看到同样的滑坡。这条规律也解释了他自己的路径：他之所以能用 Claude Code 做出别人做不出的东西（他自称是第一个琢磨出怎么用 Claude Code 做视频的人），是因为他愿意花大量时间在那些很麻烦、很耗时的环节上。而他对 AI 的判断方式也很朴素：每当你看到 AI 把某件事做得还不错，就该知道 6 到 12 个月后它会做得非常好。

### 别把身份绑在机构上

关于"为什么 MIT 让你失望"，他的回答是：哪里都有人在装模作样。MIT 有很多非常聪明的人，但也有很多人在装模作样。由此延伸出的建议是——不要把自己的身份绑在一家公司、一个机构、一个"MIT 毕业生"或"YC 创始人"的标签上。他待过的每个机构都不能说让人失望，只是这些机构不可能达到你心里的期待。判断一家实验室该不该去，真正的问题是：你能不能融入，你和谁一起工作，这个岗位适不适合你，你能不能在这里发挥最大的作用。至于霍格沃茨的比喻，他觉得外界普遍把 Anthropic 看成拉文克劳（智慧、思想领导力），但他自己更想说赫奇帕奇——那种勤奋、认真、有能力把事做完的气质，才是他体感里的 Anthropic 根基。

## 二、关键问答

**Q: 你的 YC 公司做了五年，是怎么决定该放手的？**
A: 直接原因是钱的结构。A 轮融了约 1500 万美元，团队只有七八个人，融资规模远远超出当时已经证明的进展。这让公司想被收购时变得异常困难——我们太贵了。加上我对 AI 越来越感兴趣，从 GPT-2、GPT-3 时期就在想怎么把这些技术用在游戏里，最后我选择放弃，把剩下的钱退了回去。

**Q: "融的钱太多"具体是什么意思？**
A: 就是我们融到的钱，超过了当时业务进展所能支撑的水平。这在两个层面同时出问题：对外，收购方会用你融过的金额来定价，你被自己的估值卡住了；对内，你会误以为自己已经做成了什么事，其实并没有。融资顺利反而让人失去对真实进展的校准。

**Q: 关掉公司之后你马上去了 Anthropic 吗？**
A: 没有，中间隔了大约一年，可能比一年稍短一点。我在 South Park Commons 待过一段时间，也和 Goodfire 合作过，在那里做了一些 AI 研究，还写了一个电子表格 agent。那段时间基本是四处摸索，之后才去 Anthropic，在那里待了大概一年半，可能比一年半稍短。

**Q: 为什么选 Anthropic，而不是继续自己开公司？**
A: 首先是"他们会让我去吗、我能通过吗"这种自我怀疑。然后从 Sonnet 3.5 开始，很明显 Anthropic 在编程方面是最强的，而编程显然会带来巨大的突破。等到 Opus 4.1 出来，我的感受是"天哪，太厉害了"。当时的判断是：我应该不会再创办一家公司了，那我得去其中一家实验室。

**Q: 你怎么看大家对 AI 实验室的这种崇拜？**
A: 我很纠结，我觉得这种程度的崇拜不太健康，虽然我自己多少也这样。这些实验室在某种程度上已经变成了巨大的人才黑洞，你被捧上神坛，很像当年的谷歌，但现在更夸张，因为行业里的人更多、讨论的人更多，Twitter 上还有一层刻意营造光环的意思。但实验室里的每个人也都是普通人。

**Q: OpenAI 和 Anthropic 一发产品，大家就说初创公司要被杀光了，你怎么看？**
A: Anthropic 自己不久前也只是家初创公司，当时同样看着没什么希望——OpenAI 已经在了，谷歌有所有的钱和芯片。所以我不觉得这是终局。创业是靠势头推进的游戏，想太多就会自己退出。你只能不断找产品和市场的契合点，然后往前走。过于理性的人都会得出"打不过就加入"的结论。

**Q: 你说的"勇气比天才更稀缺"是什么意思？**
A: 旧金山有很多有天赋的人，但有时候缺少勇气——敢说我要试一试，而不是去加入某家实验室。Instinct 就是个好例子：找一个非常简单的想法，认真对待，全力去做，做得比任何人都好。很多有意思的想法，只要你特别专注地解决问题，有能力，再加一点勇气，就能做。

**Q: 你的 prompt 和 AI 编程能力，是因为在 Anthropic 工作过吗？**
A: 加入之前我就已经很擅长了，在那期间确实变得更厉害。Opus 4 刚出来的时候我就在用 Claude Code 做监控数据库和事件之类的事，也就是现在大家在讨论的"软件工厂"。我也不觉得这些实验室有什么特别之处能把你变成天才——我也见过加入 Anthropic 之后带来新想法的人，新鲜感是双向的。

**Q: 什么算"播种"？**
A: 你得先去做有意思的工作，才能讲出来。而真正有意思的工作里，大部分是无聊、烦人、还有很多苦差事。一旦你不再做那些无聊的事，或者雇别人来做，你就没法再做出内容了。你会变成"整个人生都在当名人"，而不是"在做有意思的工作"。

**Q: MIT 为什么让你失望？**
A: 我觉得哪里都有人在装模作样。MIT 有很多非常聪明的人，但也有很多人在装模作样。所以我建议别把身份绑在机构上，也别去见你崇拜的人——每次见到匿名账号的本人，我都会想，不知道你是谁的时候好多了。

**Q: 在旧金山，工作和生活真的分得开吗？**
A: 很难。你的朋友也是你的人脉，这两件事分不开。我们周日下午两点录这档播客，本身就在讨论"这算工作吗"。周末跟工作沾边的事、工作饭局、跟一群同事周末去健身，这些在旧金山都太正常了——我觉得人们就是因为这些原因讨厌我们这些旧金山的人。
