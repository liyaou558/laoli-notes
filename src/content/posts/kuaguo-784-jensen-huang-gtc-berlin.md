## 一、核心观点

### 一、AI 不是软件行业，是制造业：一张五层蛋糕解释了英伟达为什么什么都做

黄仁勋开场就把定义问题摆在最前面：「问题是，AI 到底是什么？这个问题很重要。」他的答案是：AI 首先是一个制造行业。能源给先进的计算机供电，这些计算机组成 AI 工厂，工厂生产 token 也就是数字智能，模型运行在这些计算机上生成 token，最后融入每一种应用——「一个五层的蛋糕」。这个框架的作用不是科普，而是划界：如果你想参与 AI 经济，「你不会满足于只是使用 AI，你还会想要生产 AI」。计算机不再只是供人使用的工具，「现在已经成为整套机器的一部分，成为基础设施，成为生产智能的工厂」。这也解释了英伟达的产品线为什么从 GPU 一路长到交换机、存储加速、CPU、光学器件和整个数据中心参考设计——因为在这张蛋糕上，它选择同时站在最底下两层，并且把上面三层也当成自己的客户。

### 二、欧洲不是英伟达的市场，是英伟达的出生地之一

演讲的地理叙事做得很刻意。黄仁勋说英伟达在欧洲已经耕耘 33 年，而最早的三款芯片——NV1、NV2，以及后来叫 RIVA 128 的 NV3（「就是那款救了我们公司、真正让公司起飞的芯片」）——「全都是在欧洲制造的」。第一个合作伙伴是 SGS-Thomson，芯片在法国制造、在马耳他组装，然后发往世界各地。GeForce 起步时最大的客户是德国的 MediaMarkt，2000 年德国公司 ELSA 把英伟达带进工作站行业，2005 年奥迪把它带进汽车设计，2020 年开始和奔驰做自动驾驶。数据也给得很实：过去一年在欧洲投入近 100 亿美元，仅演讲前一周就从法国、英国走到瑞典再到柏林，宣布投资 14 家初创公司；33 年累计建立超过 12000 项合作关系。他反复强调的不是「我们来卖东西」，而是「欧洲正在建设自己的 AI 经济」，而这张五层蛋糕的每一层欧洲都有人在干：施耐德、西门子、西门子能源在能源与电气层，Nebius、法国的 Mistral、新公司 Firebird 在算力与云层。

### 三、十年一百万倍：摩尔定律走到头之后，靠的是「极致协同设计」

这是全场技术叙事的骨架。从 Pascal 到 Volta、Ampere、Hopper、Blackwell，再到已经全面量产的 Vera Rubin，六代架构，「过去这十年里，我们把 AI 性能提升到了原来的一百万倍」。他专门做了对照：按摩尔定律，十年大概是前五年十倍、后五年再十倍，「十年就是一百倍」。差距来自方法而非单点：不是在某一颗芯片上创新，而是在每一台计算机、软件的每一层、算法本身以及加速这些算法的架构上同时推进——「这就是我们所说的极致协同设计」。他措辞很直接：「摩尔定律基本上已经走到头了，所以我们需要这些极致协同设计的思路，从芯片到系统，从系统到系统软件，再到算法，再到整个 AI 工厂。」具体代际差：Blackwell 处理大语言模型大约是 Hopper 的 30 倍，而 Vera Rubin 又达到了 Blackwell 的 30 倍，「只用了两年时间」。

### 四、Vera Rubin 的工程细节：没有线缆、没有风扇、五分钟装一个节点

为了让「一百万倍」落地，黄仁勋把机器搬上了台。Vera Rubin 是「全球首台这样的计算机：没有线缆，没有电线，100% 液冷」——Grace Blackwell 时代组装一个节点要花两个小时，机箱里「到处都是线缆和电线」，只有 80% 液冷；Vera Rubin「组装起来不到五分钟」。旁边的 NVLink 交换机托盘负责把 72 个 GPU 连成「一个巨大的 GPU」，单颗 GPU 的算力是每秒两亿亿次浮点运算量级。Vera CPU 每时钟周期执行八条指令，配备「全球首个 LPDDR 内存系统」，在提供高带宽的同时保持能效，片间互联速度「在全球所有芯片里都是最快的」。第三台机器是 Spectrum-X 交换机：全球首个共封装光学（CPO）产品，512 个端口、每端口每秒 200 吉比特，激光器通过英伟达与台积电共同发明的 COUPE 工艺直接封装到芯片上，不必再走印刷电路板和收发器——「要不然你们看到的这一整片，都会是印刷电路板，而印刷电路板的传输能力比光缆差得多」。这些硬件拼在一起，正好对应 agent 的四类负载：思考（跑模型）、跑 harness、为知识做数据处理、用加速计算跑工具。

### 五、1 吉瓦 500 亿美元，DSX POD 把「集成」从工地搬回工厂

这是全场最有商业分量的一段。先给成本：一座 1 吉瓦的 AI 工厂，「造价大约是 500 亿美元」，包含土地、电力、厂房，以及所有的计算、网络、存储、供电、冷却，「组成占地好几英亩的 AI 工厂」。再给痛点：这样的工厂建成要几个月，「投入运营之前一个 token 都产不出来」。以一座 1 吉瓦工厂每年 400 亿美元收入计，推迟三个月就是 100 亿美元的机会成本——他现场算错了又自己纠正：「抱歉，应该是多少来着……100 亿美元的收入，换谁都会着急。」

解法是把组装前置。今天发布的 DSX POD 以 Vera Rubin NVL72 为基础，7 个液冷机架，用 17 公里的 Spectrum-X 线缆连起来，在工厂里完成集成、全部布线和测试，做完老化测试、验收通过后装进可运输的集装箱交付；干冷器取代蒸发冷却，800 伏直流电直接入架。现场只要水电配套就绪，「预计现场部署时间就能从几个月缩短到几天」。更关键的指标是「到第一个 token 的时间」：从计算设备到货到开始产出 token，原本估计四到五个月，现在可以缩到一个月左右。他的收尾口号是「以光速建成 AI 工厂」「每瓦电力产出更多智能」「更快产出第一个 token」，背后逻辑是减少闲置算力和闲置资本开支。

DSX 本身是一整套全栈 AI 工厂参考架构，计算、网络、存储、软件、供电、冷却作为一个系统协同设计，从设计到运营全程优化，起点是数字孪生：性能、用电、用水和规模「在开工前就先在虚拟环境里验证」。生态分工讲得很清楚：施耐德电气对配电和液冷做仿真，Jacobs 把它整合进 Omniverse 数字孪生，西门子评估散热、噪声和对电网的影响，Procore 支持施工阶段规划。

三个可验证的数字：其一，DSX MaxLPS 是一个端到端的电力控制闭环，动态调配电力匹配工作负载，「同样的产出，用电量减少 30%」；其二，Vera Rubin 系统采用闭环液冷，冷却液温度最高可达 45 摄氏度，在气候合适的地方用室外干冷器把热量排到空气中，「不需要蒸发水」，在 2 吉瓦规模下每天可省 5400 万升水，相当于 18 万户家庭一天的用水量；其三，17 公里线缆——他连着说了两次，「这个数字太夸张了」。

### 六、agent 的五个零件：模型、harness、沙箱、知识、工具

这是全场的概念主干，也是标题里「用公司的知识和工具」的来源。他认为 agent 由五部分组成：语言模型负责感知、推理、规划；harness 是「这个数字 agent 的外骨骼」，协调记忆（活跃记忆、工作记忆、长期记忆）与工具调用；沙箱把 harness 和系统其余部分隔离；再加上知识与工具。转折点是今年年初 OpenClaw 引入开源 agent 概念，「也真正开启了今天我们在全球看到的这一切」——agent 会思考、会推理、会迭代、会用工具，「因此会消耗大量 token，但也因此 agent 变得有用了」，于是开发得越来越多、用的人越来越多、token 消耗暴涨、GPU 需求暴涨。

他把这套结构落到英伟达自己的产品上：harness 可以是 OpenClaw、Hermes、OpenHands，也可以用 LangChain、Deep Agents 或直接用 Python 写；模型是 Nemotron；知识由 Agent 知识基础承担——Nemotron Parse、Nemotron Embed、Nemotron Re-rank（他称均为排行榜第一）、以及能对结构化数据库做预测的 Kumo；工具则是 CUDA-X 那三百多个库，让同样的活比在 CPU 上快 10 倍、50 倍、100 倍。

### 七、「安全不能只是一个愿望」：OpenShell 把策略执行放到 agent 之外

整场最锋利的一段是一支讽刺视频：要防止 agent 滥用能力，「唯一的办法就是好声好气地提出请求——请不要删除任何东西，请不要往 main 分支推送，请不要碰我的 SSH 密钥」。他的判词是：「可光靠希望保障不了安全。安全不能只是一个愿望，安全靠的是技术和工程。」

对应的产品是 OpenShell，一个安全的 agent 运行环境。核心设计原则是「在 agent 外部强制执行」：你写好策略规定每个 agent 能接触什么，OpenShell 严格执行到每一次系统调用、文件访问和网络连接；每个 agent 在独立隔离的沙箱里运行，不能直接连网，每个外发请求都要经过沙箱外的监管程序按策略检查，不在许可范围就拒绝。密钥保留在沙箱外由监管程序保管，只在请求发往获准端点时才注入——「agent 就算被攻破了，也泄露不了从没拿到过的密钥」。网关是控制平面，监管程序做决定，策略验证器用形式化验证对照权限上限检查每一次策略变更。他把这比作早期互联网：病毒遍地，直到浏览器严格限制网页能做什么，情况才改变。OpenShell 以 Apache 2.0 开源，边缘到云端都能跑，「只要两条命令就能用起来」。

### 八、Sentry：把最后一道闸门放在主机之外的硬件里

OpenShell 之外还有一层可选的硬件隔离。NVIDIA Sentry 运行在 Bluefield DPU 上，位置在主机之外、「远离 agent 的地方」，在一个通过硬件隔离的信任域内强制执行安全策略。它的抓手很巧：agent 的推理流量必须经过它，所以「如果 agent 正打算做不符合预期的事，Sentry 就会立即更新策略，切断 agent 与模型的连接，在几毫秒内把 agent 隔离起来」。它还会保存一旦被篡改就能发现的记录，供运营人员核验，用于检测、调查和响应。

黄仁勋强调这套东西的时效性：OpenShell 发布之后，从前沿 AI 实验室到操作系统公司、网络安全公司、平台公司，「全球几乎所有大公司都站出来采用」；Anthropic 与英伟达正在合作打造 Claude 的 OpenShell agent。他还提醒 adoption 是双向的——不只是服务提供方在部署 agent 时用 OpenShell，「全世界的公司也都要采用，这样你们就能接入这些 agent，让 agent 在公司内部自主运行」。因为每个任务、每个能力级别、每个使用者需要的权限都不同，权限设置、策略执行、监控都必须动态进行。

### 九、物理 AI 的三台计算机，和「每一家做工具的公司都会成为 AI 公司」

演讲后半段转向物理世界。他先纠正一个直觉：物理 AI 不等于机器人，他最喜欢的例子是通信基站——不用摄像头、不用麦克风，而是用无线电波感知世界、处理信息、推理，再通过波束成型与世界互动，「再适合 AI 不过了」。整个西方世界有 10 万个站点、上百吉瓦的分布式数据中心，未来会变成分布式 AI 基础设施；上周，经过近八年努力，英伟达和诺基亚在 T-Mobile 网络上打通了首个商用电话。另一个例子是自适应放疗：肿瘤形状会变、身体会变，机器人必须实时感知、分割、引导。

做物理 AI 需要三台计算机：训练模型的计算机、在数字孪生 Omniverse 里学技能的计算机、装在机器人身体里的计算机（车上叫 Hyperion：14 个摄像头、9 套雷达、3 个激光雷达加超声波，双 GPU 计算，含功能安全与主动安全系统）。Hyperion 新增四个品牌：大众 ID. Buzz、捷豹路虎新车型、沃尔沃车队、奔驰下一代车型。全球每年出行里程约 1 万亿英里，按每英里 1 到 2 美元计是巨大市场，但极度分散，所以要用标准架构聚合虚拟车队。

而软件侧他的判断最为反直觉：「有人说 AI 来了，软件就要完了，做工具的公司也要完了。事实恰恰相反。」AI 会让更多人使用这些工具，「每一家做工具的公司，现在都会成为 AI 公司」，不仅提供工具，还提供「特别擅长使用他们的工具」的 agent——Cadence、CrowdStrike、达索、IQVIA 都在做。他给三个案例：Lila Sciences 用 Nemotron 和 BioNeMo 设计 B 细胞淋巴瘤疗法，干实验室里跑数百万次虚拟实验，再送进由 Omniverse 和 Cosmos 驱动的自主机器人科学工厂；西门子 Erlangen 电子工厂用 Cosmos 生成虚拟原型和合成数据、用 Omniverse 数字孪生验证排产计划后才动车间；达索平台上，Aura 与 Leo 两个 agent 协作改大众高尔夫的车门让途观也能用，仿真时发现震动问题又回到设计环节。「目标不同，专业知识不同，组成部分却是一样的：开放模型、CUDA-X 加速的工具、OpenShell 安全运行环境。」

### 十、RTX Spark：把 2016 年送给 OpenAI 的那台机器，塞进笔记本

收尾回到 1993 年的个人电脑革命。四年前他们开始想：能不能让 PC 不只是工具，而是「你的专属 agent，或者私人助理」——「你跟这台计算机相处的方式，基本上就像跟一个伙伴相处」。于是有了与微软合作四年的 RTX Spark：一款代号 N1X 的芯片，台式机、笔记本、工作站三条线，「投入的工程开发工作量加起来相当于几千人各干一年」。

性能对比是全场的情绪高点：这台机器每秒 1000 万亿次浮点运算、128GB 内存；2016 年他送给「一家叫 OpenAI 的小公司」的 DGX-1，也是每秒 1000 万亿次浮点运算、128GB 内存——「唯一的区别就是，这台我能这样拿在手上，DGX-1 却要两个人才能搬上楼。」工作站版本（运行 Windows 的 DGX Station）每秒 2 亿亿次浮点运算、754GB 内存，可跑 CATIA、Autodesk、Adobe、Cadence、Synopsys。

现场演示直接把闭环跑完：用 Hermes 作 harness、Nemotron 加 OpenAI 的 GPT 模型、FreeCAD／Blender／Isaac Sim／Newton／Isaac Lab 作工具，在 RTX Spark 上规划路线、建模、搭场景、设关节执行器，再把策略放到云端几千个并行实例里训练，「每摔一次就学到一点」，策略下载回本地验证后部署到实体小机器人身上——它当场走了起来。他对着机器人说：「你们知道自己就是在这里创造出来的吗？你们是在 RTX Spark 上创造出来的。」最后落回主题：「人人都能构建 agent，欧洲的每一家公司都会成为 AI 公司。」

## 二、关键问答

Q: AI 到底是什么？为什么黄仁勋说它是制造业？
A: 他给了一个五层蛋糕：能源供电给计算机，计算机组成 AI 工厂，工厂生产 token，模型在计算机上生成 token，token 融入每一种应用。关键是「AI 是软件技术，但又不止于此」——这种计算机的运作方式有根本不同，不再只是工具，而是基础设施、是生产智能的工厂。

Q: 「生产 AI」和「使用 AI」的差别为什么重要？
A: 他说如果你只想参与 AI 经济，「你不会满足于只是使用 AI，你还会想要生产 AI」，而这在欧洲已经做得到。差别体现在蛋糕的每一层都能创造就业和增长：能源、芯片、工厂、模型、应用，缺一层就只能当别人的下游客户。

Q: 英伟达和欧洲的关系有多深？
A: 33 年。NV1、NV2、RIVA 128 都在欧洲制造，第一个伙伴是 SGS-Thomson，在法国流片、马耳他组装；GeForce 早期最大客户是德国 MediaMarkt，2000 年 ELSA 把它带进工作站。过去一年在欧洲投入近 100 亿美元。

Q: 十年一百万倍是怎么算出来的？和摩尔定律差多少？
A: 按摩尔定律十年约一百倍（前五年十倍、后五年再十倍）。英伟达靠六代架构（Pascal、Volta、Ampere、Hopper、Blackwell、Vera Rubin）加极致协同设计做到一百万倍——在芯片、系统、系统软件、算法、整个工厂每一层同时创新，而不是只堆晶体管。

Q: Blackwell 和 Vera Rubin 的代际差有多大？
A: Blackwell 处理大语言模型约是 Hopper 的 30 倍；Vera Rubin 又达到 Blackwell 的 30 倍，而且是「只用了两年时间」。他强调摩尔定律基本走到头，所以必须靠从芯片到 AI 工厂的全栈协同设计来维持这个斜率。

Q: Vera Rubin 在工程上解决了什么问题？
A: 极简。没有线缆、没有电线、100% 液冷，一个节点组装从 Grace Blackwell 的两小时（80% 液冷、到处是线）降到不到五分钟。意义是生产更快、可靠性更高、性能更好——「这是了不起的成就」。

Q: 为什么共封装光学（CPO）值得单独发布？
A: 因为传输瓶颈在电路板。Spectrum-X 是全球首个 CPO 产品，512 端口、每端口 200Gbps，激光器经光学器件直接接进芯片，用的是与台积电共同发明的 COUPE 工艺。若不这么做，「这一整片都会是印刷电路板」，而电路板传输能力远差于光缆。

Q: 一座 AI 工厂到底多少钱？
A: 1 吉瓦约 500 亿美元，含土地、电力、厂房、全部计算、网络、存储、供电、冷却，占地好几英亩。对应的收入预期是每年几百亿美元——他给的数字是每年 400 亿美元，因此推迟三个月等于损失 100 亿美元。

Q: DSX POD 到底改变了什么？
A: 把集成、布线、测试从工地搬回工厂。7 个液冷机架、17 公里 Spectrum-X 线缆在厂内装好、跑完老化测试再集装箱交付，现场只需水电就绪，部署从几个月缩到几天；设备到货到产出第一个 token 的时间从四到五个月缩到约一个月。

Q: DSX 的三个环保/效率数字是什么？
A: DSX MaxLPS 电力控制闭环让同样产出少用 30% 电；闭环液冷冷却液可达 45 摄氏度，气候合适处用干冷器排热、不蒸发水，2 吉瓦规模下每天省 5400 万升水（约 18 万户家庭一天用水）；此外 17 公里线缆本身也是可维护性的量化指标。

Q: agent 由哪五个部分组成？
A: 语言模型（感知、推理、规划）、harness（外骨骼，协调记忆与工具调用）、容纳 harness 的沙箱、知识、工具。他强调这个结构是通用的：换行业只换后两项的「专业知识与专业工具」，前三个零件可以复用。

Q: 为什么今年 token 消耗会暴涨？
A: 因为 agent 取代了单次问答。今年年初 OpenClaw 引入开源 agent 概念后，agent 会思考、推理、迭代、反复调用工具直到完成任务，每一步都在生成 token；agent 越有用，用的人越多，开发得越多，于是 token 消耗和 GPU 需求一起暴涨。

Q: 「安全不能只是一个愿望」具体指什么？
A: 指不能靠 prompt 求 agent 别删文件、别推 main、别碰 SSH 密钥。安全必须靠工程：OpenShell 在 agent 外部按策略强制执行到每一次系统调用、文件访问、网络连接，配合形式化验证检查策略变更，权限永不超过你设定的上限。

Q: OpenShell 怎么防止密钥泄露？
A: 密钥不放进沙箱，由沙箱外的监管程序保管，只有当请求发往获准端点时才注入。所以哪怕 agent 被完全攻破，它「也泄露不了从没拿到过的密钥」——因为它从来没有拿到过。

Q: Sentry 和 OpenShell 是什么关系？
A: OpenShell 是软件层隔离（内核隔离 + 运行时策略执行）；Sentry 是可选的外层硬件保险，跑在 BlueField DPU 上、主机之外的硬件信任域内。agent 的推理流量必经 Sentry，它能识别异常并在几毫秒内切断连接。

Q: 企业为什么需要自己的模型，而不是只用最强的前沿模型？
A: 因为工作里包含太多「你独有的知识和专业本领」，而你想持续提升这方面的智能。他的判断是未来每家公司都会同时使用闭源模型和自研/定制的开放模型；英伟达的策略是开放权重加数据加复现脚本，让你「知道模型的来历、完全信任模型」。

Q: 从开放模型到前沿水平，路径是什么？
A: 拿 Nemotron 这类开放模型起步，用自己的数据针对自己的场景做后训练。他举了一串例子：AI21 把 Nemotron 做到超越前沿水平、Baseten 帮客户用自己的数据微调、Trajectory 和 Harvey 做后训练、Palantir 与 Tampa General Hospital 合作。

Q: 「Agent 知识基础」解决什么问题？
A: 把公司数据变成可用的知识。非结构化文档靠 Nemotron Parse 读取理解；结构化数据靠 Nemotron Embed 关联查询与向量库、Re-rank 按相关度重排；Kumo 在结构化数据上做预测，比如供应商延期会影响哪些订单、延迟多久。

Q: 为什么说「每一家做工具的公司都会成为 AI 公司」？
A: 因为 agent 要真干活必须用专业工具，而工具背后是行业几十年的知识。AI 不会让工具消失，反而让更多人使用这些工具；工具公司会同时提供工具和「特别擅长使用自己工具」的 agent。Cadence、CrowdStrike、达索、IQVIA 都在往这个方向走。

Q: 物理 AI 为什么需要三台计算机？
A: 第一台训练模型；第二台在数字孪生里学技能——「你不能只是给 AI 编好程序就让它到现实世界里试着干什么」，所以需要 Omniverse；第三台装在机器身体里，负责实时推理与安全，车上这套叫 Hyperion，含计算机、功能安全、主动安全和为物理 AI 设计的操作系统。

Q: 为什么人形机器人可能是下一个大平台？
A: 因为标准化才能形成自我加速的循环。手机、PC、NVL72 进步快都因为配置标准化、客户基数大。机器人难在任务太杂、配置太碎，行业被切成无数定制版本，技术无法累积；人形形态「可能不是样样都完美，但很可能很多事情都能做」，因此有机会成为数量最多的配置。

Q: RTX Spark 的意义是什么？
A: 把 agent 五件套装进 PC：本地或云端模型、harness、OpenShell 安全环境、知识与工具。它每秒 1000 万亿次浮点运算、128GB 内存，和 2016 年送给 OpenAI 的 DGX-1 相同，「唯一的区别就是这台我能拿在手上」，DGX-1 却要两个人搬上楼。

Q: 现场那个机器人演示完整跑了什么流程？
A: 在 RTX Spark 上用 Hermes 作 harness、Nemotron 和 OpenAI 模型做规划，FreeCAD 建模、Blender 上材质、Isaac Sim 搭场景、Newton 模拟运动；策略放到云端几千个并行实例训练，回本地验证后部署到实体机器人，它当场走起来。

Q: 他对欧洲的最终判断是什么？
A: 三句话：人人都能构建 agent；欧洲的每一家公司都会成为 AI 公司，「毫无疑问，所有公司都会成为 AI 公司」；欧洲的 AI 经济将会蓬勃发展。他把理由落在欧洲的制造工艺上——没有哪个地区像欧洲这样擅长机电一体化、电子设备与精密机械，这正是人形机器人的底层能力。
