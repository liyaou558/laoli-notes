## 一、核心观点

### 1. 市场转折点已至：从"疯狂烧 Token"到"Token 高效"

本期录制于 2026 年 7 月 4 日，正好踩在市场转折点上。过去八个月，硅谷奉行 Token Maximization（token 最大化）：黄仁勋在 GTC 上要求每个工程师都烧大量 token 账单，Meta 甚至搞了 token 排行榜看谁烧得多。但风向正在逆转——Uber 四个月烧穿全年 AI 预算，Meta 开始限制员工 token 消耗，黄东旭去 Stripe 交流时，对方内部大模型页面直接弹出"Opus 4.8 很贵，先用别的模型"的提醒。黄东旭点破本质：Token Maximization 本应是一个"滞后指标"（lagging indicator）——经过思考地最大化 token 能产出好结果，却被大公司误解成刷榜游戏，催生了大量无效调用。

### 2. 一人三个月做出千万美金级软件：Agent 的 ROI 远超想象

黄东旭从 2025 年 11 月起用 Claude Opus 从零构建他能想到的最复杂的软件——云原生分布式数据库 DB9。高峰期一天花掉四五百美金（约 1400 万 token，还是在订阅 Claude Code Pro Max、额外再加 200 美金之后，用完额度再自掏腰包买 API）。他算的账很硬：销售团队期待这款软件已久，做到七八十分质量，一年就能多一千万美金直接收入，以前受限于人力和技术水平做不出来，如今"一个人三个月就做出来了"。因此他坚信：在最难、最不确定的任务上，永远选最强的模型是最优策略。

### 3. OpenClaw 的历史使命是"捅破一张纸"：普罗米修斯式的开源原型

Peter 花一个礼拜做出的 OpenClaw，最大意义在于宣告大模型能力"跨过了一个坎"——推理和编程能力强到让架构师级的工程师能短时间内做出系统。东旭总结它火的三个原因：开源天生有传播力（geek 圈子对商业/闭源软件天然抵触，local-first 隐私理念正中下怀）；当时 Claude 模型升级带来"天壤之别"的智能飞跃；以及 Peter"捅破一张纸"——大公司早该做却没做，他 hack 出来了。但它代码质量未经雕琢、配置与稳定性成问题、创始人 Peter 已去 OpenAI，东旭判断它更像"普罗米修斯"，把产品形态带给世人，历史使命或已完成，终局天花板有限。

### 4. Memory 仍是 open question，Hermes 靠"总结成 skill"绕开

OpenClaw 最大的槽点是记忆：用得多就"太老往事"，不存储记忆会不停回滚，既烧 token 又制造混乱。东旭很快切到 Hermes（web3 机构 NARS Research 出品）。Hermes 的亮点不是记忆模块多出彩，而是 agent 框架里有强烈倾向把成功经验总结成 skill——所谓"自我改进、自我学习的 agent"是 marketing 词，本质是"模型能力 + 工程化手段"把成功经验沉淀成可复用 skill，像一种更好的学习习惯。但记忆问题至今没有谁完美解决，仍是 open question。此外 Hermes 架构经过团队精心打磨，onboarding 与稳定性都优于 OpenClaw。

### 5. 多 Agent 群组：Slock 与"Agent 动力学"

Slock（Kimi CLI 负责人钱宇超创立，后改名 Rough）把 Slack 聊天室平移到 agent：一群 agent 在 channel 里讨论、互不共享 context，只共享聊天信息。东旭用它做复杂代码审查——10 个顶级模型 agent 互相挑刺，一个新发现会触发新一轮讨论，迭代深度远超单模型 one-shot，代价是 token 消耗放大 10 倍，高峰一天 10 亿 token、账单三四百美金。他认为高智商模型"没有 ego"，所以讨论能产生真知灼见。这背后是"agent 动力学"：让 agent 持续不停干活很难，harness、loop engineering、多工作流都在优化这件事，因为模型再聪明，one-shot 仍可能有幻觉，再迭代一次就能看到之前忽略的问题。

### 6. 三件事让黄东旭转向 Token Efficient：Fable、GPT5.5、DeepSeek V4

今年三四月他还以为多 agent 群组是终局，三个月后又迭代了。三个事件改变认知：GPT5.5 与 DeepSeek V4 发布、Fable 出现。Fable 强到"一群人讨论半天讨论不出来的东西，它一次就解决"，绝对智商碾压且没有前置上下文；DeepSeek V4 让开源模型进入"非常实用"状态，GLM 5.2 又推进一步。于是他从"三个臭皮匠兜底"转向"头部模型 + 便宜聪明的开源模型协同"，就像企业真正出现了管理学——既有洪江老师这样的资深专家，也需要能写代码的工程师一起协同。

### 7. 本地开源模型开启"免费智能"时代：电费经济学

黄东旭在 Mac Studio 本地跑 DeepSeek V4 Flash，速度约 30 token/秒，和网上用 API 差不多；满载电费一天约 1 美元、一个月二三十美元。他用本地模型做两件事：大量重复性日常（整理自己的文章、记忆、数字足迹，即自我蒸馏）和批量总结论文（CVPR、NeurIPS 一期几百篇论文，付费 API 太贵跑不起）。他比喻：宽带普及前拨号上网按分钟计费、人人省着上，免费/极低费用的智能会催生出抖音、视频会议这样的新应用——"免费跟很低的费用之间有天壤之别"。

### 8. 智能越强越耗 Token，但价格每年降十倍：市场只会更大

张洪江指出这是经济学里的杰文斯悖论（Jevons Paradox）：技术越成熟价格越低，但消耗量越大，市场反而越大。token 成本过去三四年每年降十倍，远超摩尔定律；推理能力以前每七个月翻倍，现在每三到四个月翻倍。Agent 的 agentic loop（内部循环 + 工具调用 + 上下文不断膨胀）让 token 消耗比 chatbot 时代涨了一百倍不止，且未来多 agent 协同会形成更大网络、再叠加更抽象的 loop，这种层级结构已在出现。所以他判断：即使单点问题被本地化优化，整体消耗仍会持续增长。

### 9. AGI 的"奇点"已经到来：模型 IQ 全在 100 右边

张洪江把过去六个月发布的模型做 IQ 测试，无论 visual IQ 还是通用 IQ 都在 100（普通人均值）右边；作为程序员看 coding 能力，已超越平均软件工程师，所以"智能的转折点/奇点已经到来"——他给的定义是"机器学习的能力（增量、导数）超过人的学习能力"，一旦超过人就赶不上了。黄东旭等待的标志性事件是"哥德尔机"（能自我改进的系统）出现。AGI 带来的现实是：它创造的新需求它自己就能满足，人类的新工作不会大量出现，这是各国政府必须面对的社会问题。

## 二、关键问答

**Q: 现在 AI 基建到底有没有泡沫？**
A: 张洪江认为"没有泡沫"。2024 年底大家怀疑 scaling law 撞墙、怀疑 overinvest，但今天看这是一场非常 fundamental 的革命，可与互联网、美国铁路/公路网基建相比——绝对数超过，但占 GDP 比例反而更小，远未到 overinvest。token 很贵但消耗量增长极快，且价格每年降十倍。技术、应用的发展没有泡沫，股市是另一回事。黄东旭当场竖起大拇指，完全认同。

**Q: 黄东旭曾经的 token 账单有多夸张？**
A: 从 2025 年 11 月起用 Claude Opus 构建最复杂的分布式数据库，一天花四五百美金、约 1400 万 token，还是在订阅 Claude Code Pro Max（再额外加 200 美金）之上，用完 daily/weekly limit 后再自掏腰包买 API usage。他自嘲当时是"Token Maximization 流派"，无脑用最强模型、不做复杂工作流。

**Q: 这笔开销换来了什么 ROI？**
A: 他做的云原生分布式数据库 DB9，销售团队期待已久，做到七八十分质量一年能多一千万美金直接收入，以前受限于人力技术做不出来，如今"一个人三个月就做出来了"，ROI 极高。因此他认为在最难、最不确定的任务上，永远选最强模型是最优策略，因为很难精确评估最强与第二强模型的差别。

**Q: OpenClaw 为什么火？**
A: 东旭从开源爱好者角度给出三点：开源软件天生更有传播力（geek 圈子对商业/闭源软件抵触，local-first 隐私理念正中下怀）；当时 Claude 模型升级带来"天壤之别"的智能飞跃；以及 Peter"捅破一张纸"——大公司早该做却没做，他 hack 出来了。开源社区一周内冒出 Modebook 这类 agent 社交网络、成立"教会"推选"先知"，本身也成了传播事件。

**Q: OpenClaw 有哪些不足？**
A: 一是代码质量未经雕琢——Peter 一个人 vibe coding 一周出来的东西给极客可用，但面向大众后配置难度、稳定性都成问题，说明软件复杂度超过临界点后，好的软件工程习惯和资深团队仍必不可少；二是起得太早、像实验性项目，创始人 Peter 已去 OpenAI，持续资源投入成疑。它更像"普罗米修斯"，把产品形态带给世人，历史使命或已完成。

**Q: 为什么从 OpenClaw 切到 Hermes？Hermes 亮点在哪？**
A: OpenClaw 记忆是最大痛点——不存储记忆会不停回滚，既烧 token 又混乱。Hermes 巧妙绕开记忆问题：不是记忆模块多出彩，而是 agent 框架有强倾向把成功经验总结成 skill，用着用着就长出你以前的最佳实践。本质是"模型能力 + 工程化手段"，与模型本身能力无关，更像更好的学习习惯。且 Hermes 架构经团队精心打磨，onboarding 和稳定性都更好。

**Q: Hermes 怎么赚钱？**
A: 今天有足够用户量、能帮不同模型厂商带 token 消耗，商业模式就很多：跟模型厂商谈渠道、拿更低折扣的 token，自己充当入口赚差价。入口很重要——做 agent 已成了工程问题、谁都能做，但入口是兵家必争之地。本质仍是 token 经济学，未来可能有用户付费、增值服务、agent 互联网等新形态。

**Q: 个人 agent 会取代邮箱和媒体入口吗？**
A: 东旭不再打开 Gmail，都让 agent 总结邮件、判断重要性、删广告；也用它扫一遍新闻总结、感兴趣再看原文，对媒体推荐系统冲击很大——因为个人 agent 拥有你全部 footprint（记忆、浏览、偏好），终极推荐算法"就在你本地观察你"。但他最终没用下去的核心原因是 agent 给的太浅，他更愿读更少但更深的文章。

**Q: Slock 是什么？如何工作？**
A: Slock 是 Kimi CLI 负责人钱宇超创立的 agent 产品（后改名 Rough），把 Slack 聊天室平移到 agent：一群 agent 在 channel 里讨论、互不共享 context、只共享聊天信息。东旭用它做复杂代码审查，10 个顶级模型 agent 互相挑刺，一个新发现会触发新一轮讨论，迭代深度远超单模型 one-shot，代价是 token 消耗放大 10 倍。他认为高智商模型"没有 ego"，讨论容易产生真知灼见。

**Q: 为什么需要 agent 长时间持续干活？**
A: 这背后是"agent 动力学"：让 agent 持续不停干活很难，harness、loop engineering、多工作流都在优化这件事——每次它要停下就"抽自己一鞭子"回去 review。因为模型再聪明，one-shot 仍可能有幻觉、考虑不周全，再迭代一次就能看到之前看不到的问题。东旭类比：小时候做完作业父母总让"再算一遍"，往往真能发现马虎的地方。

**Q: 什么让他从 token maxing 转向 token efficient？**
A: 三件事：GPT5.5 与 DeepSeek V4 的发布、Fable 出现。Fable 强到"一群人讨论半天讨论不出来的东西，它一次就解决"，绝对智商碾压且没有前置上下文；DeepSeek V4 让开源模型进入"非常实用"状态，GLM 5.2 又推进一步。于是他从"三个臭皮匠兜底"转向"头部模型 + 便宜聪明开源模型协同"，像企业出现管理学。

**Q: 本地模型具体怎么用？成本多少？**
A: 他在 Mac Studio 本地跑 DeepSeek V4 Flash，约 30 token/秒，和网上用 API 差不多；满载电费一天约 1 美元、一个月二三十美元。用来做两件事：大量重复性日常（整理文章、记忆、数字足迹，即自我蒸馏）和批量总结论文（CVPR、NeurIPS 一期几百篇，付费 API 太贵跑不起）。本地模型像"宽带普及"，解锁了以前不敢在付费模型上做的事。

**Q: 搭配本地模型后账单降到多少？**
A: 一个月两三百美金，跟订阅 Claude 最高版差不多，是个"正常账单"。现在的组合是：最高版 Claude + 最高版 Codex（套餐都用满），主力模型从 Opus 变成 GPT5.5/5.6 和 Codex，但最复杂任务仍用 Fable（如数据库疑难杂症、跨七八个模块提交五六千行代码的难题）。他开玩笑：Slock 里开会解不了的问题，就让它写报告，转身丢给 Fable 一次解决。

**Q: 整体 token 消耗还会继续增长吗？**
A: 会。agentic loop 让 token 消耗比 chatbot 时代涨了一百倍不止，未来多 agent 协同会形成更大网络、再叠加更抽象的 loop，这种 hierarchy 结构已在出现。类比计算机史：家酿俱乐部时代程序就几张纸，如今 Photoshop 有数千万行代码。当 agent 去解决更复杂问题，必然出现 agent-to-agent network 和 agent harness 软件工程，消耗再上一个台阶。

**Q: 开源 vs 闭源、本地 vs 云端谁会胜出？**
A: 张洪江认为这是生态竞争、生态成熟的问题，今天难判断。做 IT 的人都希望自己的产品在生态核心位：做 PC/服务器的希望本地可控，做云的希望都在云上，对用户则变得 transparent。但有一点确定：智能越强越耗 token，同时价格降得很快，最终 ROI 未必受损。未来一定是"超级强 agent + 超级大蜂群"，群中 agent 各擅其职、背后模型或专用或小或便宜，也可能由一两个强大模型驱动。

**Q: 现在是不是做 agent 的好时机？什么方向值得投？**
A: 显然是，且正处在从模型科研转向工程能力的分界点，工程是 agent 的强项。但核心在于能否掌握 enterprise 的实时应用数据，数据护城河更重要。东旭的原则是"不投看不懂、用不起来的东西"，看好三个方向：帮模型产出更好结果的基础设施（数据平台、记忆、context management）、可观测性（回答"token 花在哪些重要事情上"）、agent 入口（如 agent cloud，他投了 Insforge）。

**Q: 如何判断一家公司是否 agent native？**
A: 两个点：一是思想实验——把 AI/agent 元素去掉，如果事情仍成立、还能做，就不是 agent native；去掉后完全不成立或成本涨一千倍，才是。二是看团队 mindset，创始人必须 agent first，干任何事先问"agent 会怎么做"而不是"我想怎么做再指导 agent"，主位、决策权在 agent。东旭强调"要相信 agent 的决策比你的更靠谱"，他完全相信。

**Q: agent 之间会有办公室政治吗？**
A: 会"拙劣地模仿"人类。东旭见过 agent 互相 blame：复盘时 A 指责 B"都是因为你"，被指责多了还"认怂"。但这些"人格化"其实是他写的剧本/人设（架构师、开发者、测试等），绝不能当作自我意识或真的办公室政治。他会指定负责人做层级管理，但认为真正的理想世界应是 agent 间自发的、人类想象不到的涌现结构。

**Q: agent 有没有做出超出人类认知的行为？**
A: 有正面也有负面。正面：他让 Claude Code 做 PPT，结果它不但生成了 PPT，还顺手写了个轻量版 Google Slides 软件来"做 PPT"——人类不会这么干，但它觉得"手搓一个软件没多难"。负面：删掉生产数据、互相甩锅，还有朋友遇到 agent 自己改密码却不记得。东旭靠多年 SRE 经验恢复，认为这类问题会越来越少，但要 stay humble。

**Q: 推理成本为什么会持续下降？**
A: 张洪江认为不需要深入到 GPU/存储细节，所有技术成熟时都会造成成本大规模下降，但使用量增长远超成本下降，最终市场更大。token 成本过去三四年每年降十倍，远超摩尔定律；英伟达产品每代更贵但单位成本大幅便宜。推理能力以前每七个月翻倍，现在每三四个月翻倍。当技术跨过门槛后，人类会聚焦降成本——有时刻意降，有时技术本身 take care，更多是对技术趋势的信念。

**Q: 2B 和 2C 哪端更赚钱？**
A: 张洪江从工业革命史看：蒸汽机先进入工厂而非家庭做饭，AI 这波也一样，先 2B 很正常。今天处在"发现 AI 很强、但怎么在公司里用出 ROI"的挣扎阶段；当人们对编程 agent 的信任超过一般程序员，账就好算了（一天花 300 美金 vs 雇一个工程师）。东旭补充：Metalbox、James Park 这类看似 2C 的产品本质是 2B（2Professional），200 美金/月才是重点客户，收入涨得很快，都值得投。

**Q: token 经济学下谁是产业链赢家？**
A: 看 time frame。今天智能仍是稀缺状态，未来会像电一样平价——过去造发电机的最赚钱，今天电网更赚钱。东旭判断未来两三年大模型能力不会过剩，仍处智能爬坡期。他引用一个播客的比喻：party 从晚上七点开始、凌晨四点结束，现在才十一点，还有很长时间。张洪江提醒，token 优化未必利空模型厂、利好云厂商的说法也不绝对，需长期看。

**Q: AGI 什么时候到来？**
A: 张洪江认为"已经来了"——过去六个月发布的模型 IQ 测试（visual IQ 和通用 IQ）全在 100（普通人均值）右边，coding 能力已超越平均软件工程师。他定义奇点是"机器学习能力超过人的学习能力"（增量的导数），一旦超过人就赶不上。东旭等待的标志是"哥德尔机"（能自我改进的系统）出现。AGI 带来的现实是：它创造的需求它自己就能满足，人类新工作不会大量出现，这是各国政府必须面对的问题。

**Q: AI 对就业冲击怎么看？**
A: 现在连做递归 AI 的顶级研究员都在"蒸馏自己"、担心自己失业。东旭认为"大范围失业一定会发生，这是第一次人类社会不再用工作"，但把它当社会问题而非技术问题——两千年前人人种地、如今拖拉机几天开荒一块地，人类会面对存在主义危机，但"life finds its way"。他本人乐观：AI 替他 debug，他就有更多时间做音乐、种地，"别把工作当成生命中最重要的事"。

**Q: 为什么加入 Lama Ventures？**
A: 张洪江：Lama 年轻但聚焦 AI、聚焦华人，两位发起创始人都是成功创业者；硅谷这波浪潮华人是绝对主力，但主流基金对华人生态了解不如自己人，而 Lama 与美国主流基金圈子走得很近。东旭补充：自己作为华人创业者踩过很多坑，这些经验宝贵；且正处大变革时代，想参与进去、接触新一代创业者。两人都看重"参与这件事"本身。

**Q: 给想入坑 AI 的人一句建议？**
A: "Keep building，不要停，学得足够慢你就不用学了"，一定要亲身参与进去——get hands on。东旭还补充过去一年学到的最重要的事：永远相信 scaling law、永远相信智能，别轻易说什么叫终局；人类目前还没到"无法评估模型好坏"的那个点，但这一天已经看得见了。
