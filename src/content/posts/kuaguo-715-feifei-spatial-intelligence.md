> 本期为「跨国串门儿计划」克隆节目 #715，克隆自 a16z 对 World Labs 联合创始人 Fei-Fei、Justin、Ben（主持 Martin Casado）的英文访谈，聚焦其最新发布的世界模型 Atlas，时长约 42 分钟。本笔记基于 show notes 与嘉宾金句整理，并非完整转录稿，只挑选重点与可扫读的细节。

## 一、核心观点

1. **Atlas 的核心原语是新视角预测。** 它不只是根据文字生成画面，也不只是预测视频的下一帧。Atlas 会读取一个场景的多个视角及其空间信息，再推断虚拟相机位于时空中任意位置时应该看到什么，把空间几何纳入生成过程。嘉宾用一句话点明："而 Atlas 做的其实是新视角预测，对吧？" 这正是它与普通视频模型最根本的分野——后者建模的是时间上的演进，前者建模的是空间上的位移。

2. **生成与重建第一次在同一个模型里被统一。** 传统计算机视觉往往把像素生成、识别、3D 重建视为互不相干的不同赛道。Atlas 试图让同一套架构同时完成精确重建与具有创造性的生成，在看得见的内容与不可见的空白之间建立连续关系。嘉宾强调："这是我们第一次把像素生成和像素重建统一了起来。" 这一统一是多模态输入与相机位姿原生融合的结果，而非两个模型的拼接。

3. **三台 iPhone 就能拍出《黑客帝国》式子弹时间。** 经典子弹时间镜头需要围绕主体部署数百台相机，依赖影棚、绿幕与昂贵校准。而 Atlas 可以从三台 iPhone 拍摄的素材中重构场景，让镜头在时间冻结的瞬间自由移动。"但现在用 Atlas，我们最少只要三台相机就能做到。" 这背后正是源于生成能力对不可见区域的填补——相机数量不再是硬约束。

4. **空间智能远不止是生成 3D。** 真正的空间智能需要让模型能够生成空间内容，在空间中推理、编辑与交互，并进一步完成渲染、模拟和动作规划。Atlas 的关键进展在于为每一帧估计相机位姿，让生成的像素拥有空间依据。嘉宾的评价是："但是生成真正具备空间语境和依据的像素，绝对是另一个重大步骤，而这正是 Atlas 迈出的非常艰难的一步。"

5. **稀疏输入正在改写 3D 重建的数据逻辑。** 传统稠密重建需要从大量角度覆盖场景的每个角落，甚至要拍摄数百张照片才能建模。Atlas 通过生成能力填补不可见区域，把过去无法用于重建的随手视频、旧照片和网络素材，转化为有空间依据的 3D 世界。嘉宾给出目标数字："而我们想做的，是把它降到大概 3 张。" 数据采集的门槛由此大幅下移。

6. **机器人领域最大的瓶颈仍然是现实世界数据。** 机器人策略不是生成一张图片或一段代码，而是让 Agent 在充满意外的真实世界里行动。Atlas 可以降低 real to sim 的数据采集成本，并为训练机器人策略提供更丰富的环境变化与仿真素材。嘉宾的判断很明确："我们应该把视野放宽，认识到目前机器人领域最大的难题其实是数据。"

7. **动态世界与可编辑性是下一阶段。** Atlas 的架构已经支持动态内容，但团队认为未来还需要把动态、静态、多模态控制与可编辑性结合起来，让用户不仅能浏览世界，还能直接控制场景中的物体、布局、特征与时间变化。"我觉得可编辑性才是这里的关键。" 这标志着从"观看生成的世界"走向"操控生成的世界"。

8. **新视角预测可能像 next token prediction 一样基础。** 大语言模型通过 next token prediction 建模语言，视频模型通过 next frame prediction 建模时间变化，而 Atlas 试图用新视角预测建模空间变化。嘉宾认为，预测一个世界从新位置看起来会怎样，可能是理解物理世界与智能行为的基础能力，并直言："所以我们非常坚信，下一视点预测就相当于 next token prediction。"

## 二、关键问答

**Q: Atlas 到底是什么？和普通视频模型有什么本质区别？**
A: Atlas 是一个能同时生成、重建和模拟世界的世界模型。普通视频模型做的是 next frame prediction——沿着时间轴预测下一帧；Atlas 做的是新视角预测——给定场景的多个带位姿视角，推断虚拟相机放到时空中任意位置应当看到什么。区别在于它把空间几何显式纳入生成过程，输出的是有空间依据的像素，而不只是时间上连贯的画面。

**Q: 为什么说"新视角预测"可能是下一种基础原语？**
A: 嘉宾把认知链条串起来：语言靠 next token prediction，视频靠 next frame prediction，二者分别建模语言与时间变化。而世界从另一个位置看起来是什么样，属于空间变化，是理解物理世界与智能行为的基础能力。所以他们非常坚信"下一视点预测就相当于 next token prediction"，认为它具备成为新一类基础原语的资格。

**Q: "生成与重建统一"具体指什么？为什么重要？**
A: 过去像素生成、识别、3D 重建被当作不同赛道，各有各的模型和目标。Atlas 让同一套多模态架构既做精确重建、又做有创造性的生成，在看得见的内容与不可见的空白之间建立连续关系。嘉宾称"这是我们第一次把像素生成和像素重建统一了起来"——统一之后，模型能一边忠实还原已知区域，一边合理生成没拍到的区域。

**Q: 子弹时间那段是怎么做到的？为什么只要三台相机？**
A: 经典子弹时间是围绕主体部署数百台相机、配合影棚与严格校准拍出来的。Atlas 从三台 iPhone 的素材重构场景，借助生成能力补全不可见角度，让镜头在时间冻结瞬间自由移动。嘉宾说"现在用 Atlas，我们最少只要三台相机就能做到"，把过去昂贵、专属影棚的能力变成了日常设备可行的操作。

**Q: 三张手机画面替代数百张重建素材，意义在哪？**
A: 传统稠密重建要求大量角度覆盖几乎每个角落，甚至要拍几百张。Atlas 用生成填补不可见区域，把随手视频、旧照片、网络素材这些"过去不能用于重建"的输入变成有空间依据的 3D 世界。嘉宾给出的方向是"把它降到大概 3 张"——门槛降下来，3D 内容的供给量会发生质变。

**Q: Atlas 的输入具体包含哪些模态？怎么统一？**
A: 相比此前聚焦高斯泼溅输出的 Marble，Atlas 把文本、图像、视频、3D 信息与相机位姿统一为原生多模态输入，并以新视角预测作为核心基元。关键是为每一帧估计相机位姿，让所有模态都落到同一空间坐标系里，从而让生成出的像素天然携带空间语境。这种原生融合是它能同时重建与生成的技术前提。

**Q: 空间智能为什么"不止是生成 3D"？**
A: 生成空间内容只是第一步。嘉宾把空间智能拆成更完整的链条：生成空间内容，在空间中推理、编辑与交互，再进一步完成渲染、模拟和动作规划。也就是说，模型要能理解物体在空间中的关系、预测动作后果，而不只是输出好看的 3D 资产。Atlas 迈出的那一步是让像素具备空间依据，这是通往后续能力的地基。

**Q: 你们怎么看机器人的瓶颈？Atlas 能帮上什么？**
A: 嘉宾认为机器人策略不是生成一张图或一段代码，而是让 Agent 在充满意外的真实世界里行动，所以最大的难题其实是数据。Atlas 能降低 real to sim 的数据采集成本，提供更丰富的环境变化与仿真素材，让训练策略时不必每次都去现实里耗费大量人力采集。能理解空间、预测动作后果的世界模型，可能同时充当仿真器与规划器。

**Q: real to sim 为什么关键？**
A: 现实世界数据的采集既昂贵又难以规模化，尤其对机器人策略而言，真实环境里的意外与变化很难穷举。用 Atlas 把真实场景低成本地转成可编辑、可变化的仿真环境，就等于把"训练场"的生产成本大幅压低，同时获得现实中难得一见的环境多样性与可控变化。这是把世界模型用于机器人训练的核心动因。

**Q: Atlas 的架构支持动态内容吗？未来要补什么？**
A: 架构上已经支持动态内容，但团队认为还不够。下一步要把动态、静态、多模态控制与可编辑性结合起来，让用户不仅能浏览生成的世界，还能直接控制场景中的物体、布局、特征乃至时间变化。嘉宾强调"我觉得可编辑性才是这里的关键"——从被动观看到主动操控，是产品与模型共同的下一个台阶。

**Q: Atlas 和之前的 Marble 是什么关系？**
A: Marble 聚焦高斯泼溅输出，Atlas 则把文本、图像、视频、3D 信息与相机位姿统一为原生多模态输入，并以新视角预测作为核心基元。节目时间戳用"[09:55] 从Marble到Atlas"标记了这段演进。可以理解为从单一的 3D 表达往前推进到统一的架构与基础原语，能力边界因此明显拓宽。

**Q: 为什么强调相机位姿是"关键的一步"？**
A: 因为生成像素要有空间依据，就必须知道每个视角的相机在空间中的位置与朝向。为每一帧估计相机位姿，使不同模态能被放进同一坐标系，从而让模型推断任意新视角的内容、并保证输出与已知几何一致。嘉宾把这一步描述为"非常艰难的一步"，也正是 Atlas 区别于普通图像/视频生成模型的技术分水岭。

**Q: 空间智能和"理解物理规律"是什么关系？**
A: 在 Fei-Fei 的视角里，空间几何、物理规律与智能之间关系紧密。世界模型要能预测动作的后果，就必须先理解物体在空间中的位置、运动与相互作用。新视角预测训练出的空间一致性，正是通往物理直觉的一条路径——模型不只是记住像素，而是学会"世界从不同角度看应该长什么样"，这是理解物理世界的底层能力。

**Q: 这项能力会先改变哪些实际工作流？**
A: 节目延伸到建筑与创意工作流：可编辑的 3D 场景让设计者直接操控物体、布局与时间变化，而不必反复重拍；创作上，稀疏输入让旧照片、随手视频都能变成可自由取景的世界，子弹时间这类过去专属影棚的镜头也能低成本实现。机器人训练中的 real to sim 则是另一条更硬的落地路径。

**Q: Atlas 与普通视频模型在"数据"上的差别？**
A: 普通视频模型吃的是沿时间排列的帧，学的是时间上的连贯性；Atlas 吃的是带相机位姿的多视角素材，学的是空间上的一致性。前者需要大量时间上连续的视频，后者则能利用稀疏、随手、甚至网络上现成的图像，因为生成能力会补齐不可见区域。数据逻辑的不同，直接决定了谁更容易规模化。

## 三、备忘（碎片信息）

- **Atlas**：World Labs 最新发布的世界模型，核心原语为"新视角预测"，同时具备生成、重建与模拟世界的能力，支持文本/图像/视频/3D/相机位姿的原生多模态输入。
- **Marble**：World Labs 此前聚焦高斯泼溅（Gaussian Splatting）输出的产品/模型，是 Atlas 的前身参照。时间戳 [09:55] 专门讲"从 Marble 到 Atlas"。
- **NeRF**：神经辐射场，由嘉宾 Ben 创造，是从图像生成 3D、视觉重建与新视角合成的重要技术路线。
- **bullet time（子弹时间）**：《黑客帝国》标志性镜头效果，传统需数百台相机 + 影棚 + 精准校准；Atlas 声称三台 iPhone 素材即可实现。
- **real to sim**：把真实世界转成仿真环境，用于机器人策略训练，可降低现实数据采集成本。
- **next token prediction**：大语言模型的基础原语，建模语言。
- **next frame prediction**：视频模型的基础原语，建模时间变化。
- **新视角预测 / next view prediction**：Atlas 提出的基础原语，建模空间变化，被嘉宾类比为空间版的 next token prediction。
- **高斯泼溅（Gaussian Splatting）**：Marble 采用的 3D 表达方式。
- **相机位姿（camera pose）**：为每一帧估计相机的位置与朝向，让生成像素具备空间依据，是 Atlas 的关键一步。
- **时间戳**：[00:00] Atlas 的新视角预测；[09:55] 从 Marble 到 Atlas；[24:11] 从创作到空间智能。
- **人名**：Fei-Fei Li（李飞飞，World Labs 联合创始人，计算机视觉数十年经验）；Justin（带领团队推进 Atlas 的模型架构、训练与扩展）；Ben（NeRF 创造者，研究从图像生成 3D、视觉重建与新视角合成）；Martin Casado（a16z General Partner，本期主持）。
