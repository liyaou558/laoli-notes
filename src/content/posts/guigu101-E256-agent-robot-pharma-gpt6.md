> 播客：硅谷101
>
> 本期：E256《Agent、机器人与制药，谁先被 GPT-6 Astra 改写？》
>
> 嘉宾：许华哲（破壳机器人创始人、清华交叉信息研究院助理教授）、朱哲青 Bill（Pokey AI 创始人兼 CEO）、王胜（华盛顿大学计算机学院助理教授）
>
> 主播：泓君

这一期是硅谷101 少见的"三线并置"：同一个底层模型 GPT-6 Astra，被放进 Agent、具身智能、AI for Science 三个完全不同的落地场景里检验。有意思的是，三位嘉宾对"Astra 是不是一个大节点"给出了截然不同的答案——做模型的 Bill 说"没那么大"，做机器人的许华哲说"是飞跃"，做生物的王胜说"是，我们已经整体切换过去了"。分歧本身就是这期节目最有价值的部分：**模型能力的曲线是同一个，但每个行业的验证周期不同，于是同一条曲线在不同行业里的斜率完全不同。**

---

## 一、核心观点

### 1. Agent 的真正护城河不是模型，是"你是谁"

节目里最锋利的一个洞察来自 Bill：Meta 的 MetaMuse 给每个用户配一台云端虚拟机，两周冲到美国 App Store 榜首，但它跑在商用云 IP 上，亚马逊已经开始封它。原因不是技术，而是商家无法确认"这个 agent 代表的就是那个真人"。一旦一个用户背后站着 20 个 agent，反复比价、刷流量，商家的流量入口就被剥夺了。所以 2C agent 的关键变量是 identity（身份）与入口，而不是推理能力——云端虚拟机天然无法证明身份，本地的手机、Mac mini 或者软硬件结合的设备才可以。这也解释了为什么 Manus 早期做 browser use 被大面积封禁后，最终退回到"白领工作流"这条安全赛道；Claude Code、Codex 一类产品集体向白领效率偏移，本质上都是被巨头的 block 逼出来的路径选择。

### 2. Computer Use 的复兴，是 API 世界的退潮

Computer Use 并不新，它是"模型看屏幕、决定点哪里、敲什么字，串起几十个动作完成目标"，与 API 调用的区别是：不用给接口、不用给密码，像人一样用电脑。它这次被 Astra 重新带火，直接原因是 Agent 产品发现绕不开浏览器——购物、旅行、客服这些高频场景，第三方 App 根本不愿意开放 API。过去几年行业押注"所有工具都会 agent native、都会开 API"，现实是大量场景必须回到 browser use。Bill 的判断是最终形态一定是 mixture：能调 API 的调 API，绕不开的走浏览器。而更长远的变化可能发生在本地——如果能跑 30B 级别的小模型在你自己的 AI Box 或 AIPC 上，browser sandbox 就从云端搬回本地，用自己的家庭 IP 访问，商家没有理由再封。这会是逼着 App 厂商重写接入机制的破局点。

### 3. 对 Coding 是量变，对机器人是质变

同一个模型，两个行业的体感完全不同。Bill 的坐标是 Opus 4.5 到 4.6：那一次是"范式式转变"，从只能改几个文件、做小项目，到工具调用几乎不出错、可以自主跑长程任务。相比之下 Astra 只是"更长、更少幻觉、审美更好"，没有解决以前完全解决不了的问题。但许华哲的坐标完全不同：过去从 4.5、4.6 到 Fable，机器人的 benchmark 几乎没有变化，"原来不能做的，现在仍然不能做"；Astra 来了以后，Robot Dojo 等一批仿真 benchmark 直接失效，它拿了第一。金门大桥那个 demo 之所以震动行业，不是因为画得像，而是因为它第一次把 COT 的反思能力变成了实际动作：第一次画得差，它会想怎么画得更好，几轮迭代后画出很逼真的桥。

### 4. "分层"那一刀，被往下压了一截

具身智能的分层架构（大模型做任务规划、小模型做底层控制）行业一直有共识，争的是"这一刀切在哪儿"。传统认知里 VLM 负责"打开冰箱门、拿出西红柿、拿出鸡蛋"，底层策略负责"手怎么伸、鸡蛋怎么打"。Astra 带来的变化是它能做低层动作控制了：指令可以细到"把手往右伸两厘米""手放在冰箱门把手上"，没抓住它会说"再往前靠一靠"。许华哲的比喻很准：底下的模型变得更像反射，上层像提线木偶的操偶师。但他明确否定了"无限下压到端到端"的可能，两个硬约束：一是速度，网上所有 Astra 操作机器人的视频都要 16 倍速甚至 24 倍速才能看；二是它极度缺乏"直觉物理"——水会洒、玻璃会碎，这些人类随手就知道的事，它要靠很长的语言推理才勉强想到。

### 5. 慢不是缺陷，在科研里"慢"等于可信

王胜的使用方式很具体：白天用反馈快的模型，晚上把 Astra 拉出来设计一条长程 pipeline，让它跑一整夜。生物医学的任务常常持续 8 到 24 小时，Astra 慢，但"慢让我放心，说明它更深思熟虑"。他甚至认为 Computer Use 是这次 Astra 对科研最大的礼物：生物医学领域有一大批十几年前写的、界面糟糕、术语晦涩的必用软件，跨领域的人学习成本极高；Astra 不仅能操作（OpenAI 官方 demo 里操作的是 MultiQC 这个常用网页工具，在圈内直接出圈），还能让人通过看它操作来学习软件怎么用。它把这些软件散落在网上的 tutorial、user log、用户反馈都当成文本学进去了，所以是真的"理解"这些工具，而不只是识别按钮。

### 6. 机器人要的不是更大的模型，是更快的模型

一个反直觉的结论：机器人长期一定需要一个"能力接近 Astra 但小得多"的模型。原因是时效性——抖毛巾、接球这类高动态任务，Astra 根本做不了，它知道要快动，但它只能写代码来实现，没法直出动作。许华哲给的工程参数很实在：本地搭载最好小于 10B，十几 B 到几十 B 也能做但硬件成本会上去；走云端 API 则尺寸不限，瓶颈变成延迟和卡的新旧，准静态任务 200 毫秒甚至几百毫秒都可接受，但高动态任务必须本地，"卡一下水就洒出来了"。他自己的筷子夹球 demo 对比很能说明问题：自家模型是连续不断地试错，碰歪了换个角度再来；Astra 是每做一步都要分析原因、再给自己下指令，像人，但会陷入僵局，一旦归因错了就推不动。

### 7. AI 制药的瓶颈不在智能，在老鼠的新陈代谢

这是全场最"物理"的一段。AI 已经能给出分子式，但给不出可执行的实验方案：怎么合成、怎么储存、以什么周期给老鼠用药、在什么温度湿度下做——完成度大概只有 30%，而且模型不知道你实验室里到底有哪些仪器。更根本的是验证周期不可压缩：细胞和小鼠实验几周，灵长类猴子实验四个月、有时要做两次就是八个月，走到"license 给大药厂"通常要 6 到 12 个月，授权费一般一千万美金起。而这段时间里模型可能已经从 Astra 进化到 6.1、6.2 了——**AI 的迭代速度已经快过真实实验的反馈速度，这是结构性的错配。** 数学之所以先被攻克，是因为它可验证、不需要实验；生物医学至今没有一个完全由 AI 开发并被验证的药，根因就在这里。

### 8. 现有 Benchmark 是被设计出来"能被刷"的

王胜对 benchmark 的批评相当不客气：现在的生物医学 benchmark 本质上是 Kaggle 式的 data science 比赛，退化成了 MLE-bench 里的机器学习问题——给一份干净的生物数据，预测一个明确定义的结果。而真正的药物发现和这个 gap 极大。更尖锐的是一个悖论：**如果一个问题的答案你已知，你根本不需要研究它；所以你真正在意的问题，一定是不能被 benchmark 衡量的。** 他给出的替代方向是造"没有上限"的评测：现在 SOTA 药物能杀死 30% 的癌细胞，那就让 AI 去设计能杀死 40% 的，永远刷不爆，同时在做实验的过程中形成数据飞轮。他也提醒，能被快速实验的领域（酶、蛋白质）进步会非常快，而衰老、罕见病这类长周期问题会慢得多——模型进展几乎正比于实验周期。

### 9. 该蒸馏的不是技能，是"人怎么从零开始学"

节目结尾关于蒸馏的讨论层次很高。许华哲说机器人领域"没有那么悲哀"，因为每个人都是生活的专家——你擅长做饭、我擅长叠衣服、他擅长跳舞，家常菜水平在今天都值得被蒸馏，可能要一两年后才轮到"必须是大厨才值得被蒸馏"。王胜提到反向蒸馏：他做交叉学科，很多新东西不懂，就快速向 AI 学，学完再产出新 idea，这是互相蒸馏。而 Bill 把问题推到了更远的地方：现在模型本质上是把知识 memorize 进去、对固定场景 overfit，我们抱怨的其实是"overfit 得还不够"。真正的 general intelligence 不是把每件事做好，而是能模拟一个人从零开始学习——给一个 underfit 的 foundation model，让它在三个月交互里长成一个教授水平，这条路"我们远远没有到"。

## 二、关键问答

**Q：Astra 发布三周，最让你惊艳的 demo 是哪个？**
A：许华哲说是机器人适应能力。给它一个陌生本体，它很快能感知运动速度、运动空间，撞到桌子会说"这桌子还挺高，我是不是该把手抬高一点"——这是把 COT 的反思变成实际动作。另一个是自我升级：网上有人让它操作机械臂画金门大桥，第一遍很糟，它自己复盘再画，几轮之后相当逼真。他认为这背后是对 3D 的理解，虽然还不够动态，但已足够覆盖大量静态物理操作。

**Q：你们复现过哪些机器人任务？**
A：许华哲团队做了插花：把花插进花瓶，还特意加大难度，让花茎下端被劈成两半、有分叉。人塞不进去，Astra 会自己判断"它分叉了，我得先捏住分叉把它捏窄"，然后再往里塞。他觉得这个能力相当惊艳，说明它已经理解了一部分物理世界的操作规范。

**Q：从模型对行业的影响看，Astra 是和 Opus 4.6 同级的大节点吗？**
A：Bill 认为单看 coding 不算。4.5 到 4.6 才是范式转变：从只能改几个文件、做小项目，到工具调用几乎不出错、能自主跑长程任务。Astra 是在这个基础上"更长、幻觉更少、审美更好"，但没有解决以前完全解决不了的问题。王胜则直接反驳：他们实验室已经把 Biomedical 内部任务从 Claude 系列整体切到 GPT-6 Astra 了，对他而言这就是大节点。

**Q：Astra 的 Computer Use 在科研里具体怎么用？**
A：王胜说生物医学有一批十几年前开发的必用软件，界面差、术语多，跨领域的人用起来成本极高。Astra 只要一句简单 prompt 就能操作得不错，还能让人通过观察它操作来学习软件用法。更关键的是它把这些软件网上的 tutorial、user log、用户反馈都当文本学进去了，所以它理解的是"这个软件在干什么"，而不只是按钮在哪。

**Q：为什么 Computer Use 这次又被带火了？**
A：Bill 解释，行业一度以为所有工具都会开放 API、都会做 agent native 的接入，但购物、旅行、客服这类第三方 App 根本不愿意开接口，于是又回到 browser use——和当年 Manus 走的路一模一样。他的判断是最终会是 mixture：能调 API 的调 API，绕不开的走浏览器，而不是单一路线通吃。

**Q：MetaMuse 这类云端 Agent 的商业化能成立吗？**
A：Bill 认为短期很难。它给每个用户 1 亿免费 token，按成本折算大约每人每周 100 美元，加上云端虚拟机（内存和 CPU 都很贵，他们自己做大规模 rollout 时甚至遇到 CPU 价格追平 GPU），烧钱极夸张，而收入侧还要被商家封 IP。他判断 2C agent 要真正跑通，可能需要一个 token 完全不构成限制的产品形态。

**Q：那 2C Agent 的破局点在哪？**
A：Bill 的答案是软硬件结合。"云端虚拟机不能代表这个用户本身"，所以商家不认；而如果 agent 跑在属于这个用户的硬件上（手机、AI Box、Mac mini），identity 天然可验证，商家就愿意开放 access——因为一对一的比例下，agent 访问和真人访问对商家是一样的。这也是他坚持做 30B 级端侧模型的原因。

**Q：机器人领域，Astra 相比前几代模型的提升是量变还是质变？**
A：许华哲明确说是质变。从 Opus 4.5、4.6 到 Fable，机器人的测试表现几乎没有变化，原来做不了的现在还是做不了；而 Astra 让 Robot Dojo 等一批仿真 benchmark 直接失效、拿了第一，是"整个定性发生了变化"。这也是为什么"机器人的 GPT 时刻"这个说法在圈内被广泛接受。

**Q：Astra 会变成端到端的机器人控制器吗？**
A：许华哲认为不合理，两个硬约束。速度上，网上所有 demo 都要 16 到 24 倍速播放，否则就是纯等待；物理上，它极度缺乏直觉物理学——水会洒、玻璃会碎，这些人类随手就有的判断，它必须经过很长的语言推理。所以未来仍需要世界模型或快速小模型来做反射式反应。

**Q：Astra 为什么这么慢？**
A：模型大是一方面，更主要的是 COT 太长——虽然对外展示的 COT 是加密的（他判断展示出来的那部分并不真实），但内部推理极长、冗余度很高。他们观察到，Astra 面对简单任务和复杂任务的思考时长几乎一样：复杂任务上这是聪明，简单任务上就变成纯开销，看起来"像个内耗型人格"。

**Q：Astra 和你们自研模型在同一个任务上差在哪？**
A：以筷子夹球为例，自研模型快得多，而且是连续不断地试错——抓失败了、状态变了，换个角度再试，中间几乎没有逻辑思考。Astra 是每做一步都分析原因、再据此给自己下指令，更像人的思考过程，但代价是慢，而且容易陷入僵局：一旦归因错了，它就无法继续推进。旋转类任务上，Astra 目前也明显偏弱。

**Q：Astra 会冲击哪一类机器人公司？**
A：许华哲的判断分三类。做 sim2real 的会受冲击——他不认为仿真能训出最好的策略，Astra 的 real2sim 只是把 3D 外观做得好，物理引擎并没有因此变准，这是 hype。做本体的会受益，斯坦福有课题组两周就把 Astra 接进机械臂做家庭任务。做大脑的分两派：一派继续训更强的专用模型，一派干脆放弃自研、把 Astra 当调度器，自己专注部署。

**Q：机器人数据标注会变成什么生意？**
A：许华哲听到的说法是 OpenAI 现在只买不标注的"生数据"，因为觉得外部标注都是错的，也为了保密。于是他看到两种商业模式：卖生肉（靠管理上千上万人采数据、靠量取胜），和卖熟肉（懂最前沿模型怎么训、能说"这是 OpenAI 的标注法、这是 Pi 的标注法"，单价能翻十倍以上）。而且模型公司的研究品味很难摸，数据方还得从交易里做局部观察、反推对方的 COT。

**Q：AI 制药现在最大的瓶颈是什么？**
A：王胜说不是智能，是验证。设计一个分子、上老鼠做实验，不可避免要几周；猴子实验四个月、可能做两次八个月；走到 license 通常 6 到 12 个月。而这段时间模型可能已经换代了——AI 的迭代比真实实验快得多。数学先被攻克，正是因为可验证、不需实验；生物医学受限于自然规律，反馈太快不起来。

**Q：那 AI 制药公司为什么必须自建实验室？**
A：王胜说一定要配，而且要改造。"干实验"（in silico）和"湿实验"（试管、培养皿、老鼠）必须一起设计：一上来就把细胞准备好，只在 AI 要预测的那几步，预测完立刻把小分子放进去。如果 AI 出一个方案再移交给合作的实验人员，对方既不懂模型怎么设计、也不知道会得到什么结果，整个闭环就会非常低效。Anthropic 已经明确配了湿实验能力，并与 Adaptive Bio 合作。

**Q：现在 AI 设计实验的完成度大概多少？**
A：王胜估计约 30%，很多地方还需要人类专家改。他举了个很形象的例子：让 Astra 用一家饭店现有的食材做菜，它不会先看有什么原料，而是直接说"给你做一道海鲜大餐"——它缺的是对现实世界资源的盘点、协调和调用能力。而这个领域需要极深的 domain expertise，连教授都未必会，得是做过多轮实验的技术员才设计得出高成功率、可执行的方案。

**Q：生物实验数据的价值有多高？**
A：王胜说一条"在一个完整动物身上跑通的实验"就是一条数据，比如某分子在老鼠身上到底能不能杀死癌细胞。这种数据在互联网预训练语料里根本看不到，单价几万到几十万美金。他对比说，现在买一道奥数题都要几千美金、Terminal Bench 一道题也几千，而真实湿实验数据的价值会更高；能搭"让 AI 方便调用真实实验"的接口本身也很值钱——Adaptive Bio 就是靠这个拿到 4000 万美元融资。

**Q：如果 AI 已经比顶尖科学家更强，人类还剩什么？**
A：王胜的答案是"定义问题"。有明确定义、明确测试集的问题，AI 一定比人强；因此科学家未来的核心工作会从"解决问题、设计模型"转向"设计 benchmark、设计 evaluation、定义值得解决的问题"。他还补了一层现实理由：生物医学直接关系治病和用药，重大决策需要人类背书，就像飞机能自动飞，我们仍希望驾驶舱里有飞行员。

**Q：机器人的"GPT 时刻"之后，落地还有多远？**
A：许华哲给的时间表是 2028 年初会是通用机器人开始真正实用的节点，大约 18 个月后，人可以在家里用语言让机器人做 90% 的家务。他也承认机器人比大模型慢一倍——2023 年两者同步出发，物理世界的东西天然迭代更慢。而行业最终要的是零样本泛化：不是派五个 PhD 在工厂睡三个月做定制化部署，而是随便五个人在现场就能让它干活。

**Q：这一轮"蒸馏"的逻辑会怎么变？**
A：Bill 认为现在的模型本质还是把知识和 knowhow 硬塞进去、对固定场景 overfit，我们抱怨的其实是"overfit 得还不够"，离真正的 general 差得远。真正的下一步是蒸馏"人怎么从零开始学"：给一个 underfit 的 foundation model，让它在三个月交互里自己长成某个领域的教授水平。许华哲补了一句让人宽慰的话：机器人领域每个人都是生活专家，家常菜水平在今天都值得被蒸馏。

## 三、备忘

**产品 / 公司**

- GPT-6 Astra：OpenAI 本代旗舰。定价约 10 美元/百万 input token、50 美元/百万 output token，是 GPT-6 系列（"SoW"档）的 4-5 倍，其他常规模型的 2-3 倍以上。
- MetaMuse：Meta 的个人 Agent，给每个用户一台云端虚拟机，发布 5 天后上线，两周登顶美国 App Store；每用户 1 亿免费 token（成本约 100 美元/周）；底层疑用自研 Muse Spark，也有 rumor 指向部分 routing 到 OpenAI。
- Instinct：MetaMuse 的直接对手，一个月内估值从 25 亿美元涨到 100 亿美元。
- Jeff：TypeSafe 旗下的"系统一"模型，不写字、不推理，只对选项打概率；发布 24 天融资 8.7 亿美元，估值 75 亿美元。机器人任务上表现差（无法输入图像，需先用视觉模型转成状态），但速度快，可能适合做数据标注。
- Grokbot：xAI 面向企业的 Agent 部署产品。
- Pokey AI（Bill 的公司）：主打 30B 级端侧 / 私有算力小模型。
- 破壳机器人（许华哲）：同时走本地 <10B 与云端 API 两条路线。
- Adaptive Bio：为 Anthropic 提供湿实验接口，以 MCP 形式把 AI 的预测直接接到实验台；融资 4000 万美元。
- Isomorphic Labs（DeepMind 分拆）、Zyle（David Baker 相关）——AI 制药端到端路线的代表。
- 虚拟细胞计划：扎克伯格夫妇 BioHub 牵头，规模扩至 18 亿美元，DeepMind、Meta、Isomorphic、美国能源部、NIH 共同出钱出数据。

**模型 / 术语校正**

- 转写中的 "Cloud" = Claude；"Astro/Astron/Extra/Astrum" = Astra；"Fable" 为同期另一前沿模型（具体版本未在节目中说清）。
- "KIMI-K3""MU-SPARC 1.3" = Kimi K3 与 Muse Spark 1.3，王胜团队在 Astra 拒答生物医学问题时的替代方案。
- "ART 新酶系统"：Claude 用 21 小时自主发现的一种与 CRISPR 结构相似的新型基因编辑系统，引发基因编辑公司股价下跌；生物圈态度是"先在实验室验证再说"。
- Computer Use：模型看屏幕截图、决定点击位置与输入内容，串联几十个动作完成任务；与 API 调用的区别是不需要接口和密码。
- 干实验 / 湿实验：in silico 模拟 vs 试管、培养皿、小鼠、猴子等真实操作。
- TAMP（Task and Motion Planning）：把任务规划与运动控制合在一起做长程任务，Astra 之后这个"上一代"领域重新焕发生机。
- real2sim：用几张图快速生成可训练机器人的仿真环境，过去需要大量拍摄与手工标定。

**关键数字**

- OpenAI 解 Navier-Stokes 类数学问题：约 270 万条消息、1300 亿输出 token，按零售价折算约 2200 万美元。
- 生物医学单个人的数据量可达 2TB。
- Astra 在 Terminal Bench Science 的 biomedical 题上约 60 多分（满分 100），但仍已超过人类专家自测成绩。
- 一条完整动物实验数据：几万到几十万美金；奥数题、Terminal Bench 单题：数千美金。
- 药物授权给大药厂的里程碑费用：一般 1000 万美元以上。
- 实验周期：细胞/小鼠数周 → 猴子 4 个月（可能两轮共 8 个月）→ license 通常 6-12 个月；完整药物周期 5-10 年。
- 机器人本地模型理想尺寸 <10B；云端准静态任务可容忍 200ms-数百 ms 延迟；Astra 操作机器人的视频需 16-24 倍速播放。
- 许华哲预测：2028 年初通用机器人进入实用期，约 18 个月后可在家里用语言指挥机器人完成 90% 家务。
